# categories · 分类

- 路由：`/categories`（name `Categories`）
- 入口：`CategoriesView.vue`
- 依赖：`blogStore`、`i18nStore`

## 交互

| 元素 | 作用 |
| --- | --- |
| 卡片堆 | 斜向排列的文章卡片，选中的卡片居中并完整展示 |
| 云图 | 全屏三级筛选（领域 / 科目 / 主题），云朵代表分类 |
| 筛选胶囊 | 显示当前路径、学习 / 全部 / 娱乐、关闭按钮 |
| 浮动入口 | 右下角打开云图；左下角常驻当前筛选与数量 |
| 地址栏同步 | 筛选路径与查询参数双向同步，前进后退保持状态 |

标签来自目录层级（前 3 层），因此三级筛选与 `tags` 一一对应。

## 修改提示

- 云图的命中范围与景深是体验重点，改交互后要在移动端实测。
- 卡片点击标题为选中，进入文章走「沉浸阅读」按钮，避免误触。
- 背景在 `App.vue` 中被标记为 `is-frosted`，并显示萤火虫。
