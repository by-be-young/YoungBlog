# 形式语言与自动机理论的发展概况

## 何为形式语言

**语言**：
- 斯大林：语言是人们所理解的字和组合这些字的方法。
- 韦波斯特：语言是为大范围人群懂得、并能使用的字符以及组合这些字符的方法的一个统一体。
- 分类：自然语言（英语、汉语）、符号语言（程序设计语言、标记语言、算法等）。

**形式语言**：用数学方法将符号语言抽象成一个数学系统，对其进行严格的形式化定义，并构建适当的描述模型，发展相关的知识和理论，使之在科学实践中具有良好的指导作用。

## 研究概况

- **1956 年**，宾夕法尼亚大学的语言学家 **N. Chomsky** 第一次提出用形式语言研究自然语言的方法。
- Chomsky 关于用形式文法派生语言的思路：
  - 一组有限多个符号构成的集合 $\Sigma$，称为字母表；
  - $\Sigma$ 中所有符号串构成集合 $\Sigma^*$，$\Sigma^*$ 的每一个子集可视为 $\Sigma$ 上的一个语言 $L$；
  - 一个语言 $L$（所有句子）可以按照文法 $G_L$ 的一系列描述规则（算法）形式化地派生出来。
- 并给出了文法的 **乔姆斯基（Chomsky）体系**：
  - 0 型文法（短语结构文法或无限制文法）
  - 1 型文法（上下文有关文法）
  - 2 型文法（上下文无关文法）
  - 3 型文法（正则文法）

**识别符号语言的 A. Turing 自动机体系**：
- **1936 年**，英国数学家阿兰·图灵（A. M. Turing, 1912—1954）提出一种抽象计算模型——**图灵机（TM）**，能根据内部状态，在一个无限长磁带上进行读、写、移动等简单操作，计算所有可计算的函数；是模拟计算机算法的计算逻辑和研究可计算性的形式化描述工具。
- TM 的两个基本性质：
  - 计算对象能用有穷方式描述；
  - 计算过程必须由一系列离散的、可以机械执行的步骤组成。
- 基本的图灵机模型的物理装置：有限控制器 + 无限长磁带。控制器可左右移动、读字符、修改方格字符、改变控制器状态；模拟计算机的基本操作。
- 装置改进：单带多道；子程序功能；单带无穷；多带；多维；通用 TM。

**有穷状态自动机的发展**：
- **1951—1956 年**，数学家克林（Kleene）研究神经细胞时，基于图灵机建立了确定有穷状态自动机 DFA，用其识别语言；并证明 DFA 与 RE 的等价性。
- **1957 年**，米凯尔·拉宾 & 达纳·斯科特（Dana Stewart Scott，1976 年图灵奖）将确定状态自动机 DFA 扩展为非确定有穷状态自动机 NFA，从而简化了机器的描述建模过程，提高了解题（识别语言）速度，为其在机器翻译、文献检索的语言识别及符号处理等中的应用奠定了基础。

**核心问题**：
- 给定的形式文法和自动机描述的是否是同一符号语言？
- 两种形式化方法是否等价？如何证明？
- 二者能否在等价基础上相互模拟与转换？如何证明这种转换的正确性？
- 如何实现转换的形式化和自动化，即是否能用计算机的算法实现？

**1959 年**，N. Chomsky 发现：文法和自动机分别从派生和识别角度表达语言，并证明文法和自动机的等价性，开启了用数学方法研究形式语言的先河。

**两种计算模型的对应关系**：

| 文法类型 | 识别模型 |
|----------|----------|
| 0 型文法（无限制文法） | 图灵机 |
| 1 型文法（上下文有关文法） | 线性有界自动机 |
| 2 型文法（上下文无关文法） | 下推自动机 |
| 3 型文法（正则文法） | 有穷状态自动机 |

**1977 年**，Amir Pnueli 将自动机与逻辑建立关系，基于此发展了模型检测技术，涉及判定性、复杂性、表达能力。

## 计算模型相关研究领域

1. **可计算性问题的提出**：希尔伯特（D. Hilbert，1862—1943）纲领——是否对各个数学分支都能建立一套形式化的公理系统，使得所涉及领域内的任何命题，都可通过系统的有限步推导，判断命题是否正确。
2. **存在不可判定命题**：歌德尔（K. Godel，1906—1978）——在包含初等数论的协调的形式系统中，存在不可判定问题；即存在一个命题 $A$，无法在该系统内证明 $A$ 或 $\neg A$ 为真。
3. **可计算问题转换为可判定问题**：是否存在这样一种抽象的形式系统，它可以衡量什么问题是可以判定（可计算）的，什么问题是不可判定（不可计算）的。

**若干可计算模型**：
1. 英国数学家图灵 1936 年提出图灵机。
2. 赫尔布拉德（1932）、哥德尔（1936）、克林尼（1936）提出一般递归函数。
3. 邱奇（1933—1935）提出 $\lambda$ -演算。

**成果**：
- 邱奇证明：一般递归函数同 $\lambda$ -可定义的等价性；
- 克林尼证明：图灵可计算同 $\lambda$ -可定义的等价性；
- **邱奇-图灵论题**：一个函数是可计算的当且仅当它是图灵机可计算的（或 $\lambda$ -可定义的）。

# 学习意义与课程特点

## 深化计算机基础理论学习

1. 形式语言为计算机程序语言编译过程提供了理论基础；
2. 有穷状态自动机为数字逻辑电路等设计提供了描述手段；
3. 图灵机模型为计算机的计算理论提供了模型基础。

## 应用拓展

1. 在人工智能的自然语言理解与翻译、Web 服务标注语言词法及语法结构与模式识别等方面有着广泛的应用。
2. 为操作系统的状态变换、网络状态描述等各种模型系统的建模提供方法。

## 人才培养

形式语言与自动机理论对于计算机领域人才的计算思维能力的培养起到至关重要的作用。

**“计算思维能力”梯级式训练过程**：
- 中学数学 → 数学分析 → 离散数学 → 形式语言与自动机理论
- 具体、静止 → 变量、运动 → 离散、抽象（基本运算系统）→ 形式、模型（计算系统）
- 运算范围：实数 → 抽象集合
- 特征：孤立、单一的计算（实例计算）→ 一般、形式化的计算（类计算、模型计算）

## 课程特点

1. **抽象性**：形式语言研究如何利用数学方法抽象出符号语言的结构特征及相关的文法规则；自动机理论研究各种能自动处理符号串的计算模型；二者描述的理论基础是离散数学，内容具有一定抽象性。
2. **构造性**：课程包含大量的构造性内容，如给定语言构造生成语言的形式文法或识别语言的自动机；给定文法构造等价的自动机等。
3. **理论性**：形式语言与自动机理论的大部分内容属于理论形态，拥有完整的理论体系；包含许多定义、定理及其相关的递归证明。

# 前期准备：集合与关系

## 集合与归纳证明

- **集合的表示**：列举法、命题法。
- **集合的基数（势）**：有穷集合、可数无穷集合、不可数无穷集合。
- **集合关系的定义**：$A \subseteq B$，$A = B$。
- **集合的运算**：$A \cup B$、$A \cap B$、$A - B$、$A \times B$、$\sim A$、$\rho(A) = 2^A$ 等。
- **二元关系**：有序偶集合。
- **关系的性质**：自反性、反自反性、对称性、反对称性、传递性。
- **等价关系**：具有自反、对称、传递性质的关系。
- **等价划分与等价类**：用等价关系 $R$ 对集合 $S$ 进行的划分，每个子集 $S_i$ 为一个等价类。
- **关系的合成与闭包**：
  - 正闭包，记为 $R^+$，满足“传递”性质；
  - 克林闭包，记为 $R^*$，满足“自反、传递”性质。
- **递归定义**：构造无穷集合。
- **归纳证明**：证明无穷集合元素均具有性质 $P$。

## 关系示例

集合 $A = \{1,3,4,8\}$，集合 $B = \{0,3,5,7\}$。关系是集合元素之间存在的一种联系。例如二元关系 $<$：
$$R_< = \{(1,3),(1,5),(1,7),(3,5),(3,7),(4,5),(4,7)\}$$
$$R_< \subseteq A \times B$$
即关系是集合 $A$、$B$ 笛卡尔积的子集。

# 符号语言

## 字母表与字符串

**定义 1.1**：字母表是一个非空有限集合，通常记作 $\Sigma$，其中元素称为字母表的字符。

字母表及其字符特点：
1. 字母表具有非空、有穷性；
2. 字符具有不可分性、整体性；
3. 字符具有可区分性、可辨认性。

例：考察以下字母表：
$$\Sigma_1 = \{aa, ab, bb\}; \quad \Sigma_2 = \{a, a', b, b'\}; \quad \Sigma_3 = \{a, b, a\}.$$
其中 $\Sigma_3$ 不是字母表（元素重复，不满足可区分性）。

**定义 1.2**：设 $\Sigma_1, \Sigma_2$ 是两个字母表，$\Sigma_1, \Sigma_2$ 的乘积定义为
$$\Sigma_1 \Sigma_2 = \{ ab \mid a \in \Sigma_1 \land b \in \Sigma_2 \}.$$

例：
1. $\{0,1\}\{a,b,c\} = \{0a,0b,0c,1a,1b,1c\}$；
2. $\{a,b,c\}\{0,1\} = \{a0,a1,b0,b1,c0,c1\}$；
3. $\{aa,ab,bb\}\{0,1\} = \{aa0,aa1,ab0,ab1,bb0,bb1\}$。

**定义 1.3**：设 $\Sigma$ 是一个字母表，$\Sigma$ 的 $n$ 次幂可递归定义为
$$\Sigma^0 = \{\varepsilon\}; \quad \Sigma^n = \Sigma^{n-1}\Sigma, \quad n \ge 1,$$
其中 $\varepsilon$ 表示 $\Sigma$ 中 0 个字符（空字符）组成的串。

> **辨异**：$\{\varepsilon\}$ 与空集 $\emptyset$ 的区别。$\{\varepsilon\}$ 含有一个元素（空串），而 $\emptyset$ 不含任何元素。

**定义 1.4**：设 $\Sigma$ 是一个字母表，
- $\Sigma$ 的正闭包：$\Sigma^+ = \Sigma \cup \Sigma^2 \cup \Sigma^3 \cup \ldots$
- $\Sigma$ 的克林闭包：$\Sigma^* = \Sigma^0 \cup \Sigma \cup \Sigma^2 \cup \Sigma^3 \cup \ldots$

$\Sigma^*$ 是 $\Sigma$ 上全体字符串构成的集合。

例：
1. $\{0,1\}^+ = \{0,1,00,01,10,11,000,001,010,011,100,\ldots\}$；
2. $\{0,1\}^* = \{\varepsilon, 0,1,00,01,10,11,000,001,010,011,100,\ldots\}$；
3. $\{a,b,c\}^* = \{\varepsilon, a,b,c, aa, ab, ac, ba, bb, bc, \ldots, aaa, \ldots\}$。

**定义 1.5**：设 $\Sigma$ 是一个字母表，$\forall x \in \Sigma^*$，$x$ 叫做 $\Sigma$ 上的一个句子（字符串、符号串）。

例：
- $a^n = aa\cdots a$ 表示 $n$ 个 $a$ 组成的字符串。

**定义 1.6**：设 $\Sigma$ 是一个字母表，$\forall x \in \Sigma^*$，字符串 $x$ 中字符出现的总个数叫做该串的长度，记作 $|x|$。

例：$|ab| = 2$，$|aab| = 3$，$|a^n| = n$，$|a^0| = |\varepsilon| = 0$。

**定义 1.7**：设 $\alpha$ 和 $\beta$ 是任意两个字符串，则 $\alpha = \beta$ 当且仅当 $|\alpha| = |\beta|$，并且组成 $\alpha$ 的字符与组成 $\beta$ 的字符依次对应相同。

例：若 $\alpha = ab$，$\beta = ab$，则 $\alpha = \beta$；若 $\alpha = ab$，$\beta = ba$，则 $\alpha \neq \beta$。

**定义 1.8**：
1. 设 $\alpha$ 和 $\beta$ 是 $\Sigma^*$ 上任意的两个字符串，$\alpha$ 和 $\beta$ 的连接构成一个新句子，记作 $\alpha \cdot \beta$（简记为 $\alpha \beta$），该句子由串 $\alpha$ 后直接接串 $\beta$ 组成。
2. 对于 $n \ge 0$，字符串 $\alpha$ 的 $n$ 次幂为：
   $$\alpha^0 = \varepsilon; \quad \alpha^n = \alpha^{n-1}\alpha$$

例：设 $\Sigma = \{0,1\}$，$x = 001$，$y = 1101$；
- $x^0 = y^0 = \varepsilon$；
- $xy = 0011101$；
- $x^2 = 001001$；
- $y^4 = 1101110111011101$。

**字符串连接性质**：对于 $\Sigma^*$ 上任意字符串 $x, y, z$，连接运算具有以下性质：
1. 结合律：$(xy)z = x(yz)$。
2. 左消去律：$xy = xz \Rightarrow y = z$。
3. 右消去律：$yx = zx \Rightarrow y = z$。
4. 唯一性：存在唯一确定的 $a_1, a_2, \ldots, a_n \in \Sigma$，使得 $x = a_1 a_2 \cdots a_n$。
5. 单位元素：$\varepsilon \alpha = \alpha \varepsilon = \alpha$。

**定义 1.9**：设 $\Sigma$ 是一个字母表，任意字符串 $x, y, z \in \Sigma^*$，且 $x = yz$，则称 $y$ 是字符串 $x$ 的前缀，$z$ 是 $x$ 的后缀；如果 $z \neq \varepsilon$，则称 $y$ 是 $x$ 的真前缀；如果 $y \neq \varepsilon$，则称 $z$ 是 $x$ 的真后缀。

$\varepsilon$ 是每个字符串的前缀、后缀、子串。

例：求 $\Sigma = \{a,b\}$ 上字符串 $abaabb$ 的前缀、后缀、真前缀、真后缀？
- 前缀：$\varepsilon, a, ab, aba, abaa, abaab, abaabb$
- 真前缀：$\varepsilon, a, ab, aba, abaa, abaab$
- 后缀：$\varepsilon, b, bb, abb, aabb, baabb, abaabb$
- 真后缀：$\varepsilon, b, bb, abb, aabb, baabb$

**定义 1.10**：设 $\omega = a_1 a_2 \cdots a_n$ 是任意字符串，称字符串 $a_n \cdots a_2 a_1$ 是 $\omega$ 的逆，记作 $\omega^R$。

例：设 $\omega = abcd$，$\omega^R = dcba$。
若 $\omega = \omega^R$，则称 $\omega$ 为回文。
例：字符串 $0110110$ 和 $deed$ 都是回文。

## 符号语言及其运算性质

**定义 1.11**：设 $\Sigma$ 是任意字母表，$\forall L \subseteq \Sigma^*$，$L$ 称为字母表 $\Sigma$ 上的一个语言；$\forall x \in L$，$x$ 叫做 $L$ 的一个句子。

例：设 $\Sigma = \{0,1\}$，可定义 $\Sigma$ 上的不同语言如下：
1. $\{0,1\}$；$\{00,11\}$；$\{0,1,00,11,01,10\}$；
2. $\{0,1\}^*$；$\{00,11\}^*$；$\{0,1,00,11,01,10\}^*$；……

**定义 1.12**：设 $\Sigma_1$ 和 $\Sigma_2$ 是字母表，$L_1 \subseteq \Sigma_1^*$，$L_2 \subseteq \Sigma_2^*$，$L_1$ 和 $L_2$ 的乘积
$$L_1 L_2 = \{ xy \mid x \in L_1 \land y \in L_2 \}$$
是字母表 $\Sigma_1 \cup \Sigma_2$ 上的一个语言。

例：设 $L_1 = \{ab, ac\}$，$L_2 = \{e, bc\}$，有
$$L_1 L_2 = \{abe, abbc, ace, abc\}.$$

**语言结构特征分析示例**：设 $\Sigma = \{0,1\}$，分析下列语言的结构特征及其关系。
1. $L_1 = \{0,1\}$
2. $L_2 = \{00,01,10,11\}$
3. $L_3 = \{0,1,00,01,10,11,000,\ldots\} = \Sigma^+$
4. $L_4 = \{\varepsilon,0,1,00,01,10,11,000,\ldots\} = \Sigma^*$
5. $L_5 = \{0^n \mid n \ge 1\}$
6. $L_6 = \{0^n 1 \mid n \ge 1\}$
7. $L_7 = \{1^n \mid n \ge 1\}$
8. $L_8 = \{0^n 1^m \mid n,m \ge 1\}$
9. $L_9 = \{0^n 1^n 0^n \mid n \ge 1\}$
10. $L_{10} = \{0^n 1^m 0^k \mid n,m,k \ge 1\}$
11. $L_{11} = \{x \mid x \in \Sigma^+，且 x 中 0 和 1 的个数相同\}$
12. $L_{12} = \{0^n 1^m 0^k \mid n,m,k \ge 0\}$

问题：
- 有穷语言？无穷语言？
- $L_5 L_7 = L_6$？ $L_5 L_7 = L_8$？ $L_9 = L_{10}$？
- $L_6 \subseteq L_5 L_7$？ $L_9 \subseteq L_{10}$？ $L_6 \subseteq L_{11}$？

**语言运算性质**（定理 1.1）：设 $A, B, C, D$ 是 $\Sigma$ 上任意语言，有
1. $A \emptyset = \emptyset A = \emptyset$
2. $A \{\varepsilon\} = \{\varepsilon\} A = A$
3. $(AB)C = A(BC)$
4. 若 $A \subseteq B$ 和 $C \subseteq D$，有 $AC \subseteq BD$
5. $A(B \cup C) = AB \cup AC$
6. $(B \cup C)A = BA \cup CA$
7. $A(B \cap C) \subseteq AB \cap AC$
8. $(B \cap C)A \subseteq BA \cap CA$
9. $A^m A^n = A^{m+n}$
10. $(A^m)^n = A^{mn}$
11. 若 $A \subseteq B$，则 $A^n \subseteq B^n$
12. $A^* = \{\varepsilon\} \cup A^+$
13. $A^n \subseteq A^*$，其中 $n \ge 0$
14. $A^n \subseteq A^+$，其中 $n \ge 1$
15. $A \subseteq AB^*$
16. $A \subseteq B^*A$
17. 若 $A \subseteq B$，则 $A^* \subseteq B^*$
18. 若 $A \subseteq B$，则 $A^+ \subseteq B^+$
19. $AA^* = A^*A = A^+$
20. 若 $\varepsilon \in A$，则 $A^* = A^+$
21. $(A^*)^* = A^*A^* = A^*$
22. $(A^*)^* = (A^+)^* = A^*$
23. $(A^+)^+ = A^+A^+ = A^+$

**示例证明**：$(R^*)^* = R^*$

步骤 1：求证有 $(R^*)^n = R^*$（$n \ge 1$），施归纳于 $R^*$ 乘积的个数 $n$。
- 基础语句：设 $n=1$，$(R^*)^1 = R^*$，结论成立。
- 归纳语句：设 $n>1$，$(R^*)^n = R^*$ 结论成立，证 $(R^*)^{n+1} = R^*$ 时结论成立：
$$(R^*)^{n+1} = (R^*)^n R^* = R^* R^*$$
由归纳假设，
$$= \{\{\varepsilon\} \cup R \cup R^2 \cup R^3 \cup \cdots\} \cdot \{\{\varepsilon\} \cup R \cup R^2 \cup R^3 \cup \cdots\}$$
$$= \{\varepsilon\} \cup R \cup R^2 \cup R^3 \cup \cdots = R^*$$
由归纳原理可知，对任意整数 $n$，有 $(R^*)^n = R^*$。

步骤 2：
$$(R^*)^* = (R^*)^0 \cup (R^*)^1 \cup (R^*)^2 \cup \cdots \cup (R^*)^n \cup \cdots$$
$$= \{\varepsilon\} \cup R^* = R^* \quad \text{证毕.}$$

**核心：从集合角度理解语言**。
- 了解形式语言作为讨论可计算性、计算复杂性的应用场景。

**集合层次**：
- 集合：字母表 $\Sigma$，字母表的闭包 $\Sigma^+$、$\Sigma^*$，语言 $L \subseteq \Sigma^*$，语言的闭包 $L^+$、$L^*$，空语言 $\emptyset$。
- 集合元素：字符串 $\forall x \in \Sigma^*$，空字符串 $\varepsilon$，句子 $\forall x \in L$。
