# 预备知识：形式语言基础

## 字母表与符号串

**字母表**：符号的非空有限集，记作 Σ。

**符号串**：符号的有穷序列。空符号串记为 ε。

> 词法分析的依据：**字符**组成**单词**（符号串），单词集合就是符号串的集合。

## 符号串集合的运算

| 运算 | 定义 | 示例 |
|------|------|------|
| **相等** | 组成符号依次相等 | — |
| **长度** | 符号个数，记作 \|x\| | \|STV\| = 3 |
| **联接** | xy = XYYX | εx = xε = x |
| **集合乘积** | AB = { xy \| x∈A, y∈B } | {s, t}{u, v} = {su, sv, tu, tv} |
| **幂运算** | A⁰={ε}, Aⁿ=Aⁿ⁻¹A | — |
| **正闭包** | A⁺ = A¹ ∪ A² ∪ ... | — |
| **克林闭包** | A* = A⁰ ∪ A⁺ | — |

> **注意**：∅A = A∅ = ∅（空集乘任何集合为空集），而 {ε}A = A{ε} = A。

## 集合层次总结

| 概念 | 是集合还是元素 | 示例 |
|------|--------------|------|
| 字母表 Σ | 集合 | Σ={a, b, c} |
| 符号 | 集合的元素 | a ∈ Σ |
| 符号串 | 集合 Σ* 的元素 | ab ∈ Σ* |
| 空符号串 ε | 符号串 | ε ∈ Σ* |
| 语言 L | 集合（L ⊆ Σ*） | L={abⁿa\|n≥1} |
| 句子 | 集合 L 的元素 | aba ∈ L |
| 空语言 ∅ | 集合 | 不含任何句子 |

# 文法的形式定义

## 文法 G = (Vn, Vt, P, Z)

| 成分 | 含义 | 说明 |
|------|------|------|
| **Vn** | 非终结符号集 | 可被替换的语法成分，如 `<表达式>` |
| **Vt** | 终结符号集 | 单词符号，如 `+`、`i`、`(` |
| **P** | 产生式（规则）集合 | 形如 U → x，\|U\|=1，\|x\|≥0 |
| **Z** | 开始符号（识别符号） | Z ∈ Vn |

> **BNF 表示**：`<无符号整数> → <数字串>`，`|` 表示“或”。2 型文法（上下文无关文法）与 BNF 表示完全等价。

**示例**：无符号整数的文法

```
G[<无符号整数>]:
<无符号整数> → <数字串>
<数字串> → <数字串> <数字> | <数字>
<数字> → 0 | 1 | 2 | ... | 9
```

## 文法的等价性

若两个不同的文法 G₁ 和 G₂ 所描述的语言相同，即 L (G₁) = L (G₂)，则称 G₁ 和 G₂ 为**等价文法**。

> 已知语言构造文法时，往往没有形式化的方法，更多是凭经验构造，且构造出的文法通常不唯一。

## 构造文法的基本技巧

### 1. 枚举法（用于有限语言）

如果语言只包含有限个句子，可以直接枚举。

- 例：{00, 01, 10, 11} 的文法：
  ```
  Z → 00 | 01 | 10 | 11
  ```

### 2. 重复生成（用于需要重复次数的语言）

利用递归规则生成任意重复次数。

- 例：{0ⁿ | n ≥ 1} 的文法（左递归或右递归）：
  ```
  Z → Z0 | 0
  ```
  或
  ```
  Z → 0Z | 0
  ```

### 3. 对称生成（用于需要前后对应关系的语言）

利用自嵌入递归，同时生成前后相关的部分。

- 例：{0ⁿ1ⁿ | n ≥ 1} 的文法：
  ```
  Z → 0Z1 | 01
  ```

## 推导与语言

**推导**：用产生式的右部替换左部。记作 `=>`。

- `=>`：一步推导
- `=+>`：一步或一步以上
- `=*>`：零步或零步以上

**推导的分类**：
- **最左推导**：每次替换最左边的非终结符。
- **最右推导**（**规范推导**）：每次替换最右边的非终结符。

> 在自底向上的语法分析（如 LR 分析）中，我们只关心规范推导，因为它对应规范归约。

**语言定义**：
```
L(G[Z]) = { x | x ∈ Vt*，且 Z =+> x }
```
即：从开始符号出发，经过一步或多步推导，得到的**全部由终结符组成**的符号串的集合。

> 需要注意的是，**句型**是推导过程中产生的任意符号串（可含非终结符），而**句子**是全部由终结符组成的句型。语言是句子的集合。

## 递归文法

**递归规则**：规则右部出现与左部相同的非终结符。

| 类型 | 形式 | 示例 |
|------|------|------|
| 左递归 | U → Uy | `<数字串> → <数字串><数字>` |
| 右递归 | U → xU | — |
| 自嵌入递归 | U → xUy | — |

> **递归文法的优点**：用有穷条规则定义无穷语言。
> **左递归的缺点**：无法直接用于自顶向下的语法分析（会造成死循环），需要消除左递归。

# 短语、简单短语与句柄

这是语法分析中自底向上方法（如 LR 分析）的核心概念。

## 定义

给定文法 G[Z]，句型 w = xuy ∈ V⁺：

- 若 **Z =*> xUy**，且 **U =+> u**，则 **u** 是句型 w 相对于 U 的**短语**。
- 若上述推导中 **U => u**（一步推导），则 u 是**简单短语**。
- **句柄** = 最左简单短语。

> **直观理解**：短语是句型中某个非终结符能推出的子串。简单短语是该非终结符**一步**推出的子串。句柄是规约时最先被归约的部分。

## 查找步骤

1. 画出句型对应的**语法树**（或列出规范推导序列）。
2. 找出所有子树，子树末端叶子组成的符号串就是**短语**。
3. 其中**一步推导**得到的子树叶子是**简单短语**。
4. 最左边的简单短语 = **句柄**。

## 示例

文法：
```
<无符号整数> → <数字串>
<数字串> → <数字串><数字> | <数字>
<数字> → 0 | 1 | ... | 9
```

推导 10 的过程（最右推导/规范推导）：
```
<无符号整数> => <数字串> => <数字串><数字> => <数字串>0 => <数字>0 => 10
```

各句型的短语和句柄：

| 句型 | 短语 | 简单短语 | 句柄 |
|------|------|---------|------|
| `<无符号整数>` | 无 | 无 | 无 |
| `<数字串>` | `<数字串>` | `<数字串>` | `<数字串>` |
| `<数字串><数字>` | `<数字串><数字>` | `<数字串><数字>` | `<数字串><数字>` |
| `<数字串>0` | `<数字串>0`, `0` | `0` | `0` |
| `<数字>0` | `<数字>0`, `<数字>`, `0` | `<数字>`, `0` | `<数字>` |
| `10` | `10`, `1`, `0` | `1`, `0` | `1` |

# 语法树（推导树）

## 基本概念

- **根结点**：开始符号 Z
- **中间结点**：非终结符
- **叶结点**：终结符或非终结符
- **有向边**：表示结点间的派生关系

> **重要事实**：一个句子可以有多种推导序列（使用产生式的顺序不同），但对应的语法树形状**可以相同**。二义性指的是**语法树不唯一**，而非推导序列不唯一。

## 子树与短语

语法树中某个结点及其向下派生的部分构成一棵**子树**。

**定理**：子树的末端结点按自左向右顺序组成的符号串，就是该句型相对于该子树根的**短语**。

> 因此，找短语 → 找子树；找简单短语 → 找高度为 1 的子树（即父子关系）；找句柄 → 最左的简单短语。

## 树与推导的对应

- **推导** = 自上而下生长语法树（从根到叶）
- **归约** = 自下而上修剪语法树（从叶到根），每次剪掉一个句柄

**规范归约** = 每次剪掉当前句型的句柄（最左归约）

> **规范归约与规范推导互为逆过程**。规范归约是 LR 分析器工作的理论基础。

# 文法的二义性

## 定义（三种等价表述）

若一个文法满足以下任一条件，则称该文法是**二义性文法**：

1. 某句子存在**两棵不同的语法树**；
2. 某句子存在**两个不同的规范推导**（最右推导）；
3. 某规范句型的**句柄不唯一**。

> 二义性的根源在于文法对某些结构没有规定确定的结合规则或优先级。

## 二义性示例

文法 `E → E+E | E*E | (E) | i` 对于句子 `i+i*i` 存在两棵不同的语法树：

- 树 1 对应 `(i+i)*i` 的推导方向
- 树 2 对应 `i+(i*i)` 的推导方向

两种推导对应了两种不同的运算顺序，编译时会产生不确定性。

## 消除二义性：改写文法

通过引入优先级层次和结合性，将二义性文法改写为无二义性文法：

```
E → E+T | T      // E 处理加法（低优先级，左结合）
T → T*F | F      // T 处理乘法（中优先级，左结合）
F → (E) | i      // F 处理括号和基本因子（高优先级）
```

> **越靠上层，优先级越低；越靠下层，优先级越高**。同层产生式使用左递归实现左结合。

## 二义性的判定

在理论上已经证明：**文法的二义性是不可判定的**，即不存在一个通用算法，能通过有限步骤来判定任一文法是否有二义性。

实际解决办法：
1. 提出无二义性的**充分条件**（如 LL (1)、LR (1) 文法条件），满足这些条件的文法可以判定为无二义性；
2. 不改变二义性文法，而是规定编译算法的处理策略（如规定 `else` 与最近的 `if` 结合）。

# 文法的实用限制

## 有害规则

形如 `U → U` 的规则会引起二义性，应删除。

## 多余规则

1. **不可达符号**：不出现在任何句型中的非终结符，即从开始符号出发永远无法到达。
2. **不活动符号**：推不出任何终结符号串的非终结符。

> 不含有害规则和多余规则的文法称为**压缩过的**文法。

**示例**：文法 G[Z] 中
```
Z → B e
A → A e | e
B → C e | A f
C → C f
D → f
```
其中 D 不活动（不可达），C 也不活动（推不出终结符串），删除后得到压缩文法。

# 乔姆斯基文法分类

乔姆斯基将所有文法分为四类，每类对应不同的语言生成能力和识别自动机：

| 类型 | 名称 | 产生式形式 | 语言 | 识别自动机 |
|------|------|-----------|------|-----------|
| **0 型** | 无限制文法 | α → β（α含至少 1 个非终结符） | 递归可枚举语言 | 图灵机 |
| **1 型** | 上下文有关 | xUy → xuy（u≠ε） | 上下文有关语言 | 线性界限自动机 |
| **2 型** | 上下文无关 | U → u | 上下文无关语言 | 下推自动机 |
| **3 型** | 正则文法（右线性） | U → t 或 U → tW | 正则语言 | 有穷自动机 |

> **包含关系**：L₃ ⊂ L₂ ⊂ L₁ ⊂ L₀（即 0 型语言包含所有其他类型）。

在编译实践中，**2 型（上下文无关）文法**用于描述程序设计语言的**语法结构**（如表达式、语句、函数定义），因为它能很好地描述嵌套结构；**3 型（正则）文法**用于描述**词法规则**（如标识符、整数、运算符），因为它足够简单且识别效率高。
