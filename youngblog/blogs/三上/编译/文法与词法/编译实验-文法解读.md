# 题目要求解读

这个实验并不是要我们开始编写编译器了，而是告诉我们编译器需要编译什么语言。

后续实验，我们都会基于这个 `SysY` 语言进行编译操作。所以在正式开始之前，我们得要熟悉到底有哪些文法，保证后续实验不会漏掉哪种情况。

题目要求我们编写 6 个测试程序（即 `SysY` 语言程序），以覆盖所有的文法，并且使用文档中给出的输入输出库函数，编写输入输出文件。

程序**并不需要有意义**。你可以为了满足没覆盖过的文法，编写很多甚至没被调用的函数之类的。当然，在编写第一个程序的时候，你可以用你之前某次 C 程序作业使用的较长的代码，通常会覆盖很多情况了（当然有些文法 C 支持而 `SysY` 不支持，需要修改）。

# 程序级别

题目要求三种级别的程序分别需要 2 个。这里简单介绍一下：

（你大可以在 A 级里就覆盖所有的文法，然后随便编写几个 B 级、C 级，或者查漏补缺。）

## C 级

1. 不含 `char` 型；
2. 不含 `switch` 语句；
3. 不含“||”、“&&”；
4. 不含数组。

## B 级

1. 不含“||”、“&&”；
2. 没有短路求值（详见参考文档）；

## A 级

所有文法都覆盖。
