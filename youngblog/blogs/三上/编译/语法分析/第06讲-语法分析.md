# 语法分析概述

> 语法分析是编译过程的第二阶段，输入是单词符号串，输出是语法成分（如语法树）。

## 功能与任务

### 功能

根据文法规则，从源程序单词符号串中识别出语法成分，并进行语法检查。

### 基本任务

识别符号串 $S$ 是否为某语法成分。

## 两大类分析方法

| 分析方法 | 基本思想 | 主要问题 | 主要方法 |
| :--- | :--- | :--- | :--- |
| 自顶向下分析 | 若 $Z \Rightarrow^* S$ 则 $S \in L(G[Z])$，否则 $S \notin L(G[Z])$ | 左递归问题、回溯问题 | 递归子程序法、LL 分析法 |
| 自底向上分析 | 若 $Z \Rightarrow^* S$ 则 $S \in L(G[Z])$，否则 $S \notin L(G[Z])$ | 句柄的识别问题 | 算符优先分析法、LR 分析法 |

# 自顶向下分析

> 核心思想：从识别符号出发，试图推导出与输入串匹配的句子。分析过程是带预测的试探过程。

## 一般过程

给定符号串 $S$，若预测是某一语法成分，则可根据该语法成分的文法，设法为 $S$ 构造一棵语法树。若成功，则 $S$ 最终被识别为某一语法成分，即 $S \in L(G[Z])$；其中 $G[Z]$ 为某语法成分的文法。若不成功，则 $S \notin L(G[Z])$。

[task]
[question]
例：$S = cad$，$G[Z]$：
```text
Z ::= cAd
A ::= ab | a
```
求解 $S \in L(G[Z])$？
[\question]
[answer]
$cad \in L(G[Z])$
[\answer]
[analysis]
1. 开始：令 $Z$ 为根结点。
2. 用 $Z$ 的右部符号串去匹配输入串。完成一步推导 $Z \Rightarrow cAd$。检查 $c$ - $c$ 匹配，$A$ 是非终结符，将匹配任务交给 $A$。
3. 选用 $A$ 的右部符号串匹配输入串。$A$ 有两个右部，选第一个，完成进一步推导 $A \Rightarrow ab$。检查 $a$ - $a$ 匹配，$b$ - $d$ 不匹配（失败）。但是还不能冒然宣布 $S \in L(G[Z])$。
4. 回溯：即砍掉 $A$ 的子树，改选 $A$ 的第二右部 $A \Rightarrow a$。检查 $a$ - $a$ 匹配，$d$ - $d$ 匹配。
5. 建立语法树，末端结点为 $cad$，与输入 $cad$ 相匹配，建立了推导序列 $Z \Rightarrow cAd \Rightarrow cad$，所以 $cad \in L(G[Z])$。
[\analysis]
[\task]

## 自顶向下分析方法特点

1. 分析过程是带预测的，对输入符号串要预测属于什么语法成分，然后根据该语法成分的文法建立语法树。
2. 分析过程是一种试探过程，是尽一切办法（选用不同规则）来建立语法树的过程。由于是试探过程，难免有失败，所以分析过程需进行回溯，因此也称这种方法是带回溯的自顶向下分析方法。
3. 最左推导可以编写程序来实现，但带回溯的自顶向下分析方法在实际上价值不大，效率低。

## 左递归问题

### 左递归定义

令 $U$ 是文法的任一非终结符，文法中有规则 $U ::= U\ldots$ 或者 $U$ 与 $U\ldots$，这个文法是左递归的。

自顶向下分析的基本缺点是：不能处理具有左递归性的文法。

原因：如果在匹配输入串的过程中，假定正好轮到要用非终结符 $U$ 直接匹配输入串，即要用 $U$ 的右部符号串 $U\ldots$ 去匹配，为了用 $U\ldots$ 去匹配，又得用 $U$ 去匹配，这样无限循环下去将无法终止。如果文法具有间接左递归，则也将发生上述问题，只不过坏的圈子兜得更大。

要实现自顶向下分析，必须要消除文法的左递归。

## 消除直接左递归

### 方法一：使用扩充的 BNF 表示来改写文法

例：
```text
E ::= E+T | T        ⇒ E ::= T{+T}
T ::= T*F | T/F | F  ⇒ T ::= F{*F|/F}
```

改写后的文法消除了左递归，且可以证明改写前后的文法是等价的：
$L(G_{\text{改前}}) = L(G_{\text{改后}})$

- 规则一（提因子）

若 $U ::= xy | xw | \ldots | xz$，则可改写为 $U ::= x(y|w|\ldots|z)$。
若 $y = y_1y_2$，$w = y_1w_2$，则 $U ::= x(y_1(y_2|w_2)|\ldots|z)$。
若有规则 $U ::= x | xy$，则可以改写为 $U ::= x(y|\varepsilon)$。注意：不应写成 $U ::= x(\varepsilon|y)$。

提因子法不仅有助于消除直接左递归，而且有助于压缩文法的长度，使我们能更有效地分析句子。

- 规则二

若有文法规则 $U ::= x | y | \ldots | z | Uv$，其特点是具有一个直接左递归的右部并位于最后。这表明该语法类 $U$ 是由 $x$ 或 $y$ 或 $\ldots$ 或 $z$ 其后随有零个或多个 $v$ 组成。
$U \Rightarrow Uv \Rightarrow Uvv \Rightarrow Uvvv \Rightarrow \ldots$
可以改写为：
$U ::= (x|y|\ldots|z)\{v\}$

通过以上两条规则，就能消除文法的直接左递归，并保持文法的等价性。

### 方法二：将左递归规则改为右递归规则

- 规则三

若 $P ::= P\alpha | \beta$，则可改写为：
```text
P  ::= βP'
P' ::= αP' | ε
```

### 应用示例

例 1：$E ::= E+T | T$。右部无公因子，所以不能用规则一。为了使用规则二，令 $E ::= T | E+T$。由规则二可以得到 $E ::= T\{+T\}$。

例 2：$T ::= T*F | T/F | F$。
$T ::= T(*F|/F) | F$（规则一）
$T ::= F | T(*F|/F)$
$T ::= F\{(*F|/F)\}$（规则二）
即 $T ::= F\{*F|/F\}$。
右递归：
```text
T  ::= FT'
T' ::= *FT' | /FT' | ε
```

### 消除左递归方法总结

| 方法 | 适用规则 | 改写结果 |
| :--- | :--- | :--- |
| 提因子 | $U ::= xy \mid xw \mid \ldots \mid xz$ | $U ::= x(y \mid w \mid \ldots \mid z)$ |
| 规则二 | $U ::= x \mid y \mid \ldots \mid z \mid Uv$ | $U ::= (x \mid y \mid \ldots \mid z)\{v\}$ |
| 右递归 | $P ::= P\alpha \mid \beta$ | $P ::= \beta P'$，$P' ::= \alpha P' \mid \varepsilon$ |

## 消除一般左递归

一般左递归也可以通过改写文法予以消除。消除所有左递归的算法：

1. 把 $G$ 的非终结符整理成某种顺序 $A_1, A_2, \ldots, A_n$，使得：
```text
A1 ::= δ1 | δ2 | ... | δk
A2 ::= A1 r ...
A3 ::= A2 u | A1 v ...
...
```
2. 执行：
```text
for i := 1 to n do
begin
  for j := 1 to i-1 do
    把每个形如 Ai ::= Aj r 的规则替换成
    Ai ::= (δ1|δ2|...|δk) r,
    其中 Aj ::= δ1|δ2|...|δk 是当前全部 Aj 的规则；
  消除 Ai 规则中的直接左递归
end
```
3. 化简由 2 得到的文法即可。

### 示例

文法 $G[S]$：
```text
S ::= Qc | c
Q ::= Rb | b
R ::= Sa | a
```
该文法无直接左递归，但有间接左递归：
$S \Rightarrow Qc \Rightarrow Rbc \Rightarrow Sabc$，所以 $S \Rightarrow Sabc$。

非终结符顺序重新排列：
```text
R ::= Sa | a
Q ::= Rb | b
S ::= Qc | c
```

步骤：
1. 检查规则 $R$ 是否存在直接左递归：$R ::= Sa | a$，无。
2. 把 $R$ 代入 $Q$ 的有关选择，改写规则 $Q$：$Q ::= Sab | ab | b$。
3. 检查 $Q$ 是否存在直接左递归：无。
4. 把 $Q$ 代入 $S$ 的右部选择：$S ::= Sabc | abc | bc | c$。
5. 消除 $S$ 的直接左递归：$S ::= (abc|bc|c)\{abc\}$。

最后得到文法：
```text
S ::= (abc|bc|c){abc}
Q ::= Sab | ab | b
R ::= Sa | a
```
其中关于 $Q$ 和 $R$ 的规则是多余的。经过压缩后：
```text
S ::= (abc|bc|c){abc}
```
可以证明改写前后的文法是等价的。由于对非终结符的排序不同，最后得到的文法在形式上可能不一样，但不难证明它们的等价。

## 回溯问题

### 什么是回溯

分析工作要部分地或全部地退回去重做叫回溯。

### 造成回溯的条件

文法中，对于某个非终结符号的规则其右部有多个选择，并根据所面临的输入符号不能准确地确定所要的选择时，就可能出现回溯。

### 回溯带来的问题

严重的低效率，只有在理论上的意义而无实际意义。

效率低的原因：
1. 语法分析要重做。
2. 语义处理工作要推倒重来。

设文法 $G$（不具左递归性），$U \in V_n$，$U ::= \alpha_1 | \alpha_2 | \alpha_3$。

### FIRST 集定义

$\text{FIRST}(\alpha_i) = \{a \mid \alpha_i \Rightarrow^* a\ldots, a \in V_t\}$

为避免回溯，对文法的要求是：
$\text{FIRST}(\alpha_i) \cap \text{FIRST}(\alpha_j) = \varnothing \quad (i \neq j)$

## 消除回溯的途径

### 改写文法

对具有多个右部的规则反复提取左因子。

例 1：$U ::= xV | xW$，其中 $U, V, W \in V_n$，$x \in V_t^+$。
改写为 $U ::= x(V|W)$，更清楚地表示为：
```text
U ::= xZ
Z ::= V | W
```
注意：问题到此并没有结束，还需要进一步检查 $V$ 和 $W$ 的首符号是否相交。若 $V ::= ab|cd$，$\text{FIRST}(V)=\{a,c\}$；$W ::= de|fg$，$\text{FIRST}(W)=\{d,f\}$。只要不相交就可以根据输入符号确定目标；若相交，则要代入，并再次提取左因子。如：$V ::= ab$，$W ::= ac$，则 $Z ::= a(b|c)$。

例 2：文法 $G$：
```text
<程序> ::= <分程序> | <复合语句>
<分程序> ::= begin <说明串>; <语句串> end
<复合语句> ::= begin <语句串> end
```
$\text{FIRST}(<\text{分程序}>) = \{begin\}$，$\text{FIRST}(<\text{复合语句}>) = \{begin\}$。
改写文法：
```text
<程序> ::= begin (<说明串>; <语句串> end | <语句串> end)
```
引入 `<程序*>`：
```text
<程序>  ::= begin <程序*>
<程序*> ::= <说明串>; <语句串> end | <语句串> end
```
对于 `<程序*>`：
$\text{FIRST}(<\text{说明串}>; <\text{语句串}> end) = \{real, integer, boolean, array, function, procedure\}$
$\text{FIRST}(<\text{语句串}> end) = \{标识符, goto, begin, if, for\}$
不相交。

### 超前扫描

当文法不满足避免回溯的条件时，即各选择的首符号相交时，可以采用超前扫描的方法，即向前侦察各输入符号串的第二个、第三个符号来确定要选择的目标。这种方法是通过向前多看几个符号来确定所选择的目标，从本质上来讲也有回溯的味道，因此比第一种方法费时，但是假读仅仅是向前侦察情况，不作任何语义处理工作。

例：
```text
<程序> ::= <分程序> | <复合语句>
<分程序> ::= begin <说明串>; <语句串> end
<复合语句> ::= begin <语句串> end
```
这两个选择的首符号是相交的，故读到 $begin$ 时并不能确定该用哪个选择，这时可采用向前假读进行侦察，此例题只需假读一次就可以确定目标。因为 `<说明串>` 的首符集为 $\{real, integer, \ldots, procedure\}$，而 `<语句串>` 的首符集为 $\{标识符, if, for, \ldots, begin\}$。只要超前假读得到的是“说明”的首符，便是第一个选择；若是“语句”的首符，就是第二个选择。

## 文法的两个条件

为了在不采取超前扫描的前提下实现不带回溯的自顶向下分析，文法需要满足两个条件：
1. 文法是非左递归的；
2. 对文法的任一非终结符，若其规则右部有多个选择时，各选择所推出的终结符号串的首符号集合要两两不相交。

### 定义

$\text{FIRST}(\alpha_i) = \{a \mid \alpha_i \Rightarrow^* a\ldots, a \in V_t\}$
为避免回溯，对文法的要求是：
$\text{FIRST}(\alpha_i) \cap \text{FIRST}(\alpha_j) = \varnothing \quad (i \neq j)$

在上述条件下，就可以根据文法构造有效的、不带回溯的自顶向下分析器。

还有一种情况：
```text
E ::= Ua
U ::= a | ε
```
此时需要引入 $\text{FOLLOW}$ 集。

### FOLLOW 集定义

$\text{FOLLOW}(A) = \{a \mid Z \Rightarrow^* \ldots Aa\ldots, a \in V_t; A \in V_n, Z \text{ 识别符号}\}$
该集合称为 $A$ 的后继符号集合。特殊地，若 $Z \Rightarrow^* \ldots A$，则 $\# \in \text{FOLLOW}(A)$。

不带回溯的充分必要条件是：对于 $G$ 的每一个非终结符 $A$ 的任意两条规则 $A ::= \alpha | \beta$，下列条件成立：
1. $\text{FIRST}(\alpha) \cap \text{FIRST}(\beta) = \varnothing$
2. 若 $\beta \Rightarrow \varepsilon$，则 $\text{FIRST}(\alpha) \cap \text{FOLLOW}(A) = \varnothing$

## FIRST 集与 FOLLOW 集

### FIRST 定义

$\text{FIRST}(\alpha) = \{a \mid \alpha \Rightarrow^* a\ldots, a \in V_t; \alpha \in V^*\}$，若 $\alpha \Rightarrow^* \varepsilon$，则 $\varepsilon \in \text{FIRST}(\alpha)$。该集合称为 $\alpha$ 的头符号集合。

### FOLLOW 定义

$\text{FOLLOW}(A) = \{a \mid Z \Rightarrow^* \ldots Aa\ldots, a \in V_t; A \in V_n, Z \text{ 识别符号}\}$。该集合称为 $A$ 的后继符号集合。特殊地，若 $Z \Rightarrow^* \ldots A$，则 $\# \in \text{FOLLOW}(A)$。

### 构造集合 FIRST 的算法

设 $\alpha = X_1X_2\ldots X_n$，$X_1 \in V_n \cup V_t$（即 $X_1 \in V$），求 $\text{FIRST}(\alpha)$。
首先求出组成 $\alpha$ 的每一个符号 $X_i$ 的 FIRST 集合：
1. 若 $X_i \in V_t$，则 $\text{FIRST}(X_i) = \{X_i\}$。
2. 若 $X_i \in V_n$ 且 $X_i ::= a\ldots | \varepsilon$，$a \in V_t$，则 $\text{FIRST}(X_i) = \{a, \varepsilon\}$。
注：FIRST 集合中可以有 $\varepsilon$。

若 $X_i \in V_n$ 且 $X_i ::= y_1y_2\ldots y_k$，则按如下顺序计算 $\text{FIRST}(X_i)$：
1. $\text{FIRST}(X_i) \leftarrow \text{FIRST}(y_1) - \{\varepsilon\}$；
2. 若 $\varepsilon \in \text{FIRST}(y_1)$，则将 $\text{FIRST}(y_2) - \{\varepsilon\}$ 加入 $\text{FIRST}(X_i)$；
3. 若 $\varepsilon \in \text{FIRST}(y_1)$ 且 $\varepsilon \in \text{FIRST}(y_2)$，则将 $\text{FIRST}(y_3) - \{\varepsilon\}$ 加入 $\text{FIRST}(X_i)$；
4. 若 $\varepsilon \in \text{FIRST}(y_1)$ 且 $\ldots$ 且 $\varepsilon \in \text{FIRST}(y_{k-1})$，则将 $\text{FIRST}(y_k) - \{\varepsilon\}$ 加入 $\text{FIRST}(X_i)$；
5. 若 $\varepsilon \in \text{FIRST}(y_1) \cap \ldots \cap \text{FIRST}(y_k)$，则将 $\varepsilon$ 加入 $\text{FIRST}(X_i)$。

注意：要顺序往下做，一旦不满足条件，过程就要中断进行。得到 $\text{FIRST}(X_i)$，即可求出 $\text{FIRST}(\alpha)$。

### 构造集合 FOLLOW 的算法

设 $S, A, B \in V_n$。算法：连续使用以下规则，直至 FOLLOW 集合不再扩大：
1. 若 $S$ 为识别符号，则把 `#` 加入 $\text{FOLLOW}(S)$ 中。
2. 若 $A ::= \alpha B \beta$（$\beta \neq \varepsilon$），则把 $\text{FIRST}(\beta) - \{\varepsilon\}$ 加入 $\text{FOLLOW}(B)$。
3. 若 $A ::= \alpha B$ 或 $A ::= \alpha B \beta$，且 $\beta \Rightarrow \varepsilon$，则把 $\text{FOLLOW}(A)$ 加入 $\text{FOLLOW}(B)$。
注：FOLLOW 集合中不能有 $\varepsilon$。

### 示例：文法 $G[E]$ 的 FIRST 与 FOLLOW

文法：
```text
E  ::= TE'
E' ::= +TE' | ε
T  ::= FT'
T' ::= *FT' | ε
F  ::= (E) | i
```

求 FIRST：
```text
FIRST(F)  = { (, i }
FIRST(T') = { *, ε }
FIRST(T)  = FIRST(F) - {ε} = { (, i }
FIRST(E') = { +, ε }
FIRST(E)  = FIRST(T) - {ε} = { (, i }
FIRST(TE') = FIRST(T) - {ε} = { (, i }
FIRST(+TE') = { + }    FIRST(ε) = { ε }
FIRST(FT') = FIRST(F) - {ε} = { (, i }
FIRST(*FT') = { * }    FIRST(ε) = { ε }
FIRST( (E) ) = { ( }   FIRST(i) = { i }
```

求 FOLLOW：
```text
FOLLOW(E)  = { #, ) }
FOLLOW(E') = FOLLOW(E) = { #, ) }
FOLLOW(T)  = { +, ), # }
FOLLOW(T') = FOLLOW(T) = { +, ), # }
FOLLOW(F)  = { *, +, ), # }
```

| 非终结符 | FIRST | FOLLOW |
| :--- | :--- | :--- |
| E | { (, i } | { #, ) } |
| E' | { +, ε } | { #, ) } |
| T | { (, i } | { +, ), # } |
| T' | { *, ε } | { +, ), # } |
| F | { (, i } | { *, +, ), # } |

# 递归子程序法

> 又称递归下降分析法，核心思想：为每个非终结符编写一个分析子程序，通过子程序间的递归调用实现语法分析。

## 基本做法

对语法的每一个非终结符都编一个分析程序，当根据文法和当时的输入符号预测到要用某个非终结符去匹配输入串时，就调用该非终结符的分析程序。

如文法 $G[Z]$：
```text
Z ::= UV
U ::= ...
V ::= ...
```
则 $Z$ 的分析程序、$U$ 的分析程序、$V$ 的分析程序分别对应。

注：消除左递归后，可有其它递归：
```text
U ::= ...U...
U ::= ...W...
W ::= ...U...
```

## 示例：文法 $G[Z]$

文法：
```text
Z ::= '(' U ')' | aUb
U ::= dZ | U | d | e
```
1. 检查并改写文法：
```text
Z ::= '(' U ')' | aUb
U ::= (dZ | e){d}
```
改写后无左递归且首符集不相交：$\{(\} \cap \{a\} = \varnothing$，$\{d\} \cap \{e\} = \varnothing$。
2. 检查文法的递归性：
$Z \Rightarrow \ldots U \ldots \Rightarrow \ldots Z \ldots$，所以 $Z \Rightarrow \ldots Z \ldots$；
$U \Rightarrow \ldots Z \ldots \Rightarrow \ldots U \ldots$，所以 $U \Rightarrow \ldots U \ldots$。
因此，$Z$ 和 $U$ 的分析程序要编成递归子程序。

## 算法框图说明

非终结符号的分析子程序的功能是：用规则右部符号串去匹配输入串。
在进入某个非终结符的分析程序时，其所要分析的语法成分的第一个符号已读入 `sym` 中。在分析子程序的出口前，一定要读取下一个符号到 `sym` 中。

说明：
- 非终结符号的分析子程序功能，是用规则右部符号串去匹配输入串。
- 要注意子程序之间的接口。在程序编制时，进入某个非终结符的分析程序前，其所要分析的语法成分的第一个符号已读入 `sym` 中了。
- 递归子程序法对应的是最左推导过程。
- 在上面的分析过程中，我们强调一定要消除左递归，但允许存在右递归或自嵌入递归。正是由于在子程序的调用过程中允许（直接或间接的）递归调用，这种方法才得名递归子程序法。

# 用递归子程序法构造语法分析程序的例子

## 文法

```text
<语句> ::= <变量> := <表达式>
         | IF <表达式> THEN <语句>
         | IF <表达式> THEN <语句> ELSE <语句>
<变量> ::= i | i '[' <表达式> ']'
<表达式> ::= <项> | <表达式> + <项>
<项> ::= <因子> | <项> * <因子>
<因子> ::= <变量> | '(' <表达式> ')'
```
改写文法：
```text
<语句> ::= <变量> := <表达式>
         | IF <表达式> THEN <语句>
         | IF <表达式> THEN <语句> ELSE <语句>
<变量> ::= i ['[' <表达式> ']']
<表达式> ::= <项> { + <项> }
<项> ::= <因子> { * <因子> }
<因子> ::= <变量> | '(' <表达式> ')'
```

## 子程序说明

语法分析程序所要调用的子程序：
- `nextsym`：词法分析程序，每调用一次读进一个单词，单词的类别码放在 `sym` 中。
- `error`：出错处理程序。

## 递归下降程序框架

```pascal
PROCEDURE state;  /* 语句分析子程序 */
IF sym = 'IF' THEN
BEGIN
  nextsym;
  expr;
  IF sym ≠ 'THEN' THEN error
  ELSE BEGIN
    nextsym;
    state;
    IF sym = 'ELSE' THEN
    BEGIN
      nextsym;
      state;
    END
  END
END
ELSE BEGIN
  var;
  IF sym ≠ ':=' THEN error
  ELSE BEGIN
    nextsym;
    expr;
  END
END
```

```pascal
PROCEDURE var;  /* 变量 */
IF sym ≠ 'i' THEN error
ELSE BEGIN
  nextsym;
  IF sym = '[' THEN
  BEGIN
    nextsym;
    expr;
    IF sym ≠ ']' THEN error
    ELSE nextsym;
  END
END
```

```pascal
PROCEDURE expr;
BEGIN
  term;
  WHILE sym = '+' DO
  BEGIN
    nextsym;
    term;
  END
END;
```

```c
void statement() {
    if (sym == IFTK) {
        getsym();
        expr();
        if (sym != THENTK) error();
        else {
            getsym();
            statement();
            if (sym == ELSETK) {
                getsym();
                statement();
            }
        }
    } else {
        var();
        if (sym != ASSIGN) error();
        else {
            getsym();
            expr();
        }
    }
}

void var() {
    if (sym != IDENFR) error();
    else {
        getsym();
        if (sym == LBRACK) {
            getsym();
            expr();
            if (sym != RBRACK) error();
            else getsym();
        }
    }
}

void expr() {
    term();
    while (sym == PLUS) {
        getsym();
        term();
    }
}

void term() {
    factor();
    while (sym == MULT) {
        getsym();
        factor();
    }
}

void factor() {
    if (sym == LPARENT) {
        getsym();
        expr();
        if (sym != RPARENT) error();
        else getsym();
    } else {
        var();
    }
}

void main() {
    getsym();
    statement();
}

void error() {
    printf(" syntax error !\n");
}
```
