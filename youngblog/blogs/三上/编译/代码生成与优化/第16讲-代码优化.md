# 局部优化

局部优化指在**基本块内**进行的优化。

## 常见局部优化技术

| 优化技术 | 英文 | 说明 |
|----------|------|------|
| 常量合并 | Constant Folding | 编译时计算常量表达式 |
| 运算强度削弱 | Arithmetic Simplification | 用廉价运算替代昂贵运算（如乘2改左移） |
| 复写传播 | Copy Propagation | 用 `a=b` 中的b替换后续对a的引用 |
| 常量传播 | Constant Propagation | 用常量值替换变量引用 |
| 死代码删除 | Dead Code Elimination | 删除不再被使用的赋值语句 |
| 公共子表达式删除 | Common Subexpression Elimination | 重复计算的表达式只算一次 |

## 数据流分析基础

**数据流分析**用于获取数据在程序执行路径中如何流动的信息，是局部优化和全局优化的基础。

典型分析问题：
- 某个变量在特定执行点是否还"存活"
- 某个变量的值是在什么地方定义的
- 某个定义点的值可能在哪些执行点被使用

## 数据流方程

核心方程：

$$out[S] = gen[S] \cup (in[S] - kill[S])$$

- $S$：某条语句（或基本块、语句集合）
- $in[S]$：进入该语句时的数据流信息
- $out[S]$：该语句末尾得到的数据流信息
- $gen[S]$：该语句本身产生的数据流信息
- $kill[S]$：该语句注销（使失效）的数据流信息

## 公共子表达式删除

追踪所有**可用表达式**（Available Expressions）：

- 对赋值 `a = b + c`，可用表达式集合变换为：$(A - \{a\}) \cup \{b+c\}$
  - 先删除所有含a的表达式（a被重新赋值），再加入新产生的表达式 `b+c`
- 若某表达式在当前点已可用，则后续出现时可直接引用之前的计算结果，实现删除

## 死代码删除与活跃变量分析

**变量的活性（Liveness）**：变量在某点之后是否还会被使用。

对赋值 `a = b + c`，活跃变量集合从后向前计算：

$$in[S] = use[S] \cup (out[S] - def[S])$$

即 $(L - \{a\}) \cup \{b, c\}$：
- 先删除被定义的变量a，再加入被使用的变量b、c
- **从后向前**分析（backward analysis）

若一个赋值语句的目标变量在其后不再活跃，则该赋值为死代码，可删除。

## 优化的组合应用

实际优化中多种技术交替使用、反复迭代：
1. 公共子表达式删除 → 产生复写语句
2. 复写传播 → 替换变量引用
3. 死代码删除 → 清除不再使用的赋值
4. 常量传播 + 常量合并 → 进一步化简

每轮优化可能为下一轮创造新机会，直到达到不动点。

本讲聚焦基本块内的局部优化：六类常用优化技术的核心是数据流分析；数据流方程 $out=gen \cup (in-kill)$ 是统一框架；可用表达式分析（向前）支撑公共子表达式删除，活跃变量分析（向后）支撑死代码删除；多种优化需组合迭代才能充分发挥效果。
