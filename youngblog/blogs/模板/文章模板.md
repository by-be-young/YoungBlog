# 文章标题

开头先写结论或本文要解决的问题，控制在两三段内。

## 背景

说明为什么记录这篇内容、前置知识或环境。

## 正文

### 要点一

正文段落。引用站内另一篇文章使用内部引用语法（见扩展语法参考）。

### 要点二

代码示例：

```js
const answer = 42
```

图片示例（复制后替换为真实路径）：

```markdown
![配图](../图片/示例.webp)
```

## 自测

- [ ] 能复述本节的核心结论
- [ ] 能独立完成示例

## 练习

```markdown
[task]
题干：下列说法正确的是？

[question]下面哪个选项正确？[\question]

[options]
A. 选项一
B. 选项二
C. 选项三
[\options]

[answer]B[\answer]

[analysis]因为……所以选 B。[\analysis]
[\task]
```

> 结束标记是 `[\task]`（反斜杠），不是 `[/task]`。

## 小结

用三到五条收束全文，避免重复正文。
