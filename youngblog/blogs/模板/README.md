# 模板目录

`blogs/模板/` 存放写作模板与草稿。`scripts/generate.js` 会跳过整个目录，
因此这里的 Markdown **不会**被收录为文章。

## 用法

1. 复制 `文章模板.md` 到目标目录（例如 `blogs/三上/编译/`）。
2. 重命名为文章标题（文件名会成为默认标题）。
3. 填 frontmatter，删掉模板中的说明文字。
4. 运行 `node scripts/generate.js` 或 `npm run dev` 查看效果。

## 为什么不能放在 `blogs/` 根目录

生成器会扫描 `blogs/` 下的所有 `.md`（模板目录除外）。放在根目录的空文件或草稿
都会被当成正式文章收录，出现在首页、归档与搜索里，并且无法从界面删除。

## 草稿约定

- 未完成的文章留在 `blogs/模板/`，或用文件名前缀 `草稿-` 并接受它被收录。
- 不建议用 frontmatter `draft: true`：当前生成器不识别该字段。
