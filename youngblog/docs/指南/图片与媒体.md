# 图片与媒体

站点是静态站点，图片体积直接决定首屏体验。所有公共图片位于 `public/assets/`，
文章配图可以放在 `blogs/` 下随文章发布。

## 1. 目录约定

| 目录 | 用途 |
| --- | --- |
| `public/assets/avatar.png` / `.webp` | 头像 |
| `public/assets/blog_bg.png` / `.webp` | 博客卡片默认背景 |
| `public/assets/detail_bg.png` / `.webp` | 详情页背景 |
| `public/assets/images/welcome.*` | 首页 Hero 主视觉 |
| `public/assets/images/lantern_festival.*` | 首页卡片缩略图 |
| `public/assets/images/background/` | 背景轮播候选图 |
| `public/assets/images/快速链接/` | 友链卡片图 |
| `public/assets/卜算子·元旦晚会/` 等 | 文章专属图片目录 |
| `public/music/` | 背景音乐 mp3 |
| `blogs/图片/` | Obsidian 裸文件名图片的默认落点 |

## 2. WebP 生成

`scripts/optimize-images.mjs` 维护一份 `MANIFEST`。新增需要优化的图片时：

1. 把原图放进 `public/assets/...`。
2. 在 `MANIFEST` 中登记源文件与目标尺寸上限。
3. 运行：

```bash
npm run optimize:images          # 仅生成缺失的 .webp
npm run optimize:images -- --force  # 全部重建
```

脚本不会删除原图：WebP 用于现代浏览器，原图作为回退与源文件保留。
引用时优先用 `.webp`；`index.html` 的 preload 与 `useEntryLoader` 的默认背景也要同步。

## 3. 画质校验

```bash
npm run check:images
```

输出 PSNR / MAE / MaxDiff：

| 指标 | 参考 |
| --- | --- |
| PSNR ≥ 40 dB | 视觉无损 |
| PSNR ≥ 45 dB | 基本无法分辨 |
| MaxDiff 突然接近 255 | 通常是 alpha 处理问题（脚本已做 alpha 预乘） |

## 4. 尺寸查询

```bash
node scripts/image-info.mjs public/assets/images/welcome.png
```

仅解析 PNG / JPEG 文件头，不依赖 sharp，适合快速确认素材尺寸。

## 5. 背景轮播

- 运行时读取 `public/data/background-images.json`，为空则回退
  `useEntryLoader` 的 `DEFAULT_BACKGROUND_IMAGES`（`bg1.png` / `bg2.webp` / `bg3.webp`）。
- 生成器当前扫描的是仓库根目录的 `assets/images/background`，该目录不存在，
  因此清单恒为空。**这是既有行为**，不要为了「修好」而改路径，否则线上背景会突然变化。
- 若确实要启用清单，需要同时评估首屏体积与 `index.html` 的 preload。

## 6. 文章配图

```markdown
![[樱花1.jpg]]            → /blogs/图片/樱花1.jpg
![](./images/图1.png)     → 相对文章目录
![](assets/images/background/bg2.webp) → 站点根
```

建议：

- 照片类素材优先 WebP，单张控制在 300 KB 以内。
- 截图类 PNG 可保留，但避免超过 1 MB。
- 同一文章的多张图放同一目录，命名语义化（`内存布局.png`），不要用 `1.png` 堆积。

## 7. 音乐

- 文件位于 `public/music/`，由设置面板选择曲目。
- 浏览器要求用户手势后才能播放；`App.vue` 在首次点击/按键时初始化音频。
- 新增曲目需同步 `SettingsModal.vue` 的曲目列表与文案键。

## 8. 字体

- 站点书法字体为 `src/assets/fonts/仓耳今楷01-W04.ttf`（约 18 MB）。
- 字体在 `global.css` 以 `@font-face` 引入，属于入场加载器等待的资源。
- 替换字体时同步 `index.html` preload（如新增 Web 字体）与
  `docs/架构/样式与主题.md`。

- [ ] 首屏图片没有明显增大（对比 `npm run build` 的产物大小）。
- [ ] 新增大文件已确认必要，避免仓库膨胀。
