# 新增页面或功能

以新增「留言板」页面为例，完整走一遍从目录到路由、文案、样式与文档的流程。

## 1. 建目录

```text
src/features/guestbook/
├── GuestbookView.vue
├── components/            # 仅该页面使用的组件
│   └── MessageCard.vue
└── README.md
```

规则：

- 视图命名 `<Feature>View.vue`，目录用小写 kebab-case。
- 只有该页面使用的组件放 `features/<name>/components/`。
- 两个及以上页面使用的组件才上移到 `src/shared/components/`。

## 2. 写视图

```vue
<template>
  <main class="guestbook-page">
    <h1 class="guestbook-title">{{ t('guestbook_title') }}</h1>
  </main>
</template>

<script setup>
import { useI18nStore } from '@/shared/stores/i18nStore'

const i18n = useI18nStore()
const t = i18n.t
</script>

<style scoped>
.guestbook-page {
  min-height: 100vh;
  padding: 120px 20px 60px;
}
</style>
```

要点：

- 页面外层统一 `<main>`；顶部留白要避开固定导航栏。
- 所有用户可见文案走 i18n。
- 页面级样式写在 `scoped` 中，不污染全局。

## 3. 注册路由

编辑 `src/router/index.js`，在合适位置加入：

```js
{
  path: '/guestbook',
  name: 'Guestbook',
  component: () => import('../features/guestbook/GuestbookView.vue'),
  meta: { title: '留言板' }
}
```

注意：

- 使用**相对路径** `../features/...`（与现有路由一致）。
- `name` 会被 `App.vue` 用于判断背景蒙版与萤火虫页面，命名保持 PascalCase。
- `meta.title` 会被全局守卫拼成 `留言板 | YoungBlog`。

## 4. 补三语文案

在 `src/shared/stores/i18nStore.js` 的 `zh` / `en` / `ja` 三个对象中同时添加：

```js
guestbook_title: '留言板',
guestbook_empty: '还没有留言',
```

键名使用页面前缀（`guestbook_`），避免与现有键冲突。

## 5. 加入导航（可选）

编辑 `src/shared/layout/AppNavbar.vue` 的菜单数组：

```js
{ path: '/guestbook', key: 'guestbook', icon: 'fas fa-comment-dots' }
```

图标使用 FontAwesome 免费图标（`fas` / `far`）。移动端抽屉会复用同一份数组。

## 6. 数据与状态

| 需求 | 放置 |
| --- | --- |
| 页面私有状态 | 视图内 `ref` / `computed` |
| 跨页面共享 | `src/shared/stores/<name>Store.js` |
| 站点数据请求 | 优先放 Store；一次性页面数据可在视图内 fetch，但必须用 `resolveUrl` |
| 可复用行为 | `src/shared/composables/useXxx.js` |

如果新增 `public/data/*.json`，同步更新
[data-schemas](../参考/数据结构参考.md) 与 `useEntryLoader` 的预取清单（若首屏需要）。

## 7. 样式与响应式

- 复用现有变量与渐变，不引入新的高饱和色。
- 至少验证 1280 / 900 / 480 三档宽度。
- 移动端注意导航抽屉、底部安全区（`env(safe-area-inset-bottom)`）。
- 动画遵循 `prefers-reduced-motion`。

## 8. 配置页面行为（可选）

如果页面需要特殊背景（毛玻璃 / 强蒙版）或萤火虫，修改 `src/app/App.vue`：

```js
const showFireflies = computed(() => ['archive', 'guestbook'].includes(route.name?.toLowerCase()))
```

这类改动属于全局行为，必须在 `docs/架构/样式与主题.md` 登记。

## 9. 文档与验收

1. 新增 `src/features/guestbook/README.md`（目的、入口、依赖、关键行为）。
2. 更新 [module-map](../架构/模块地图.md) 的目录树。
3. 更新 [文档索引](../文档索引.md)（如有新增长期文档）。
4. 运行：

```bash
npm run lint
npm run build
node scripts/check-docs.mjs
```

5. 手动验收：直接访问、刷新、带 hash 前进后退、移动端、子路径模式（`npm run build:github`）。

## 10. 不要做的事

- 不要在 `features` 之间互相导入视图。
- 不要把页面私有组件提前放进 `shared`。
- 不要为新页面复制一套新的全局 CSS。
- 不要忘记 `meta.title` 与三语文案，否则界面会出现 `undefined` 或标题为空。
