# 本地开发

## 1. 前置条件

| 项 | 要求 |
| --- | --- |
| Node.js | `^22.18.0` 或 `>=24.12.0`（见 `package.json` / `.nvmrc`） |
| 包管理器 | npm（仓库提交 `package-lock.json`，请勿混用 pnpm / yarn） |
| 浏览器 | 现代 Chromium / Firefox / Safari，需支持 `backdrop-filter` 与 ES2022 |
| 系统 | Windows / macOS / Linux 均可；Windows 建议 PowerShell 7 |

## 2. 首次启动

```bash
npm ci
cp .env.example .env   # 当前仓库没有 .env，可跳过
npm run dev
```

开发服务器默认 `http://localhost:5173`，`server.open=true` 会自动打开浏览器。

## 3. 数据与内容

`npm run dev` **不会**执行 `scripts/generate.js`，它直接读取现有的
`public/data/blogs.json`。因此：

| 场景 | 需要做的事 |
| --- | --- |
| 只改 Vue / CSS | 直接 `npm run dev` |
| 新增或修改文章 | 先 `node scripts/generate.js`，再启动 / 刷新 |
| 改了 frontmatter 的 series / chapter | 重新生成，系列页才会更新 |
| 新增图片 | 放入 `public/assets/...`，必要时运行 `npm run optimize:images` |

`blogs/` 下的 Markdown 在开发模式下由 Vite 直接从仓库根目录提供，
详情页通过 `fetch(resolveUrl(contentFile))` 读取。

## 4. 常用端口

| 端口 | 用途 |
| --- | --- |
| 5173 | Vite 开发服务器 |
| 4173 | `npm run preview` 默认端口 |
| 4173 | `scripts/preview-server.mjs` 默认端口（与 preview 冲突时用 `--port` 指定） |

## 5. 预览构建产物

```bash
npm run build
node scripts/preview-server.mjs --port 4180
```

该服务器会先找 `dist/`，再回退到仓库根目录，因此 `blogs/*.md` 与 `public/assets` 都能访问，
最接近线上部署行为。只用 `npm run preview` 时，`dist/blogs` 已存在也可以正常阅读。

## 6. 代码检查

```bash
npm run lint     # oxlint --fix + eslint --fix
npm run format   # prettier 格式化 src/
```

两者都会**改写文件**。提交前先看 `git diff`，避免把无关文件一起格式化。

## 7. Windows 注意事项

- 仓库使用 LF 换行（`.gitattributes`），不要用会强制 CRLF 的编辑器设置。
- 中文路径（`blogs/图片/`、`public/assets/图片/`）在 PowerShell 下正常；
  若脚本参数包含中文，使用引号包裹。
- `npm run dev` 若端口被占用，Vite 会自动切换端口，以终端输出为准。

## 8. 常见启动问题

| 现象 | 处理 |
| --- | --- |
| `Unsupported engine` | 升级 Node 到 22.18+ 或 24.12+ |
| 首页无文章 | 确认 `public/data/blogs.json` 存在且为数组；运行 `generate.js` |
| 详情页 404 | 未构建时检查 `contentFile` 路径；构建后检查 `dist/blogs/` |
| 字体不生效 | 确认 `src/assets/fonts/` 存在且 `global.css` 的 `../fonts/` 相对路径未变 |
| 样式错乱 | 检查 `main.js` 的 CSS 导入顺序是否被改动 |

更多排查见 [troubleshooting](../运维/故障排查.md)。
