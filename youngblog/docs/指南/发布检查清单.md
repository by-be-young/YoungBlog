# 发布检查清单

适用于内容更新与代码发布。按顺序执行，任何一步失败都先修复再继续。

## 1. 变更范围

- [ ] `git status` 中没有 `dist/`、`node_modules/`、临时截图、`.obsidian/workspace.json`。
- [ ] `public/data/blogs.json` 的 diff 只包含预期新增 / 修改的文章。
- [ ] 没有为了「顺手」改动无关文件（尤其是全量格式化）。

## 2. 内容检查

- [ ] 新文章 frontmatter 完整（`title` / `date`，必要时 `series` / `chapter`）。
- [ ] 文章目录层级符合 `blogs/<学年>/<主题>/<小节>/`，标签与分类符合预期。
- [ ] 图片路径在本地与构建后都能访问。
- [ ] 公式、Mermaid、代码块、任务清单至少各抽查一处。

## 3. 构建

```bash
npm run lint
npm run build
```

- [ ] `generate.js` 输出的文章数与预期一致。
- [ ] 构建无 ERROR；chunk 体积警告可接受。
- [ ] `dist/blogs/` 存在且包含最新文章。

## 4. 双模式验证

```bash
npm run build:github
node scripts/preview-server.mjs --port 4180
```

- [ ] 根路径模式（`npm run build`）资源正常。
- [ ] 子路径模式（`build:github`）资源、数据、文章均 200。
- [ ] 刷新任意详情页不 404（Hash 路由）。
- [ ] 背景、字体、头像、音乐正常。

## 5. 页面抽查

至少覆盖：

| 页面 | 检查点 |
| --- | --- |
| 首页 | 入场加载屏、背景轮播、推荐、最近更新、资料卡 |
| 归档 | 时间轴、学习/娱乐筛选、移动端折叠 |
| 分类 | 云图筛选、卡片堆、地址栏同步 |
| 系列 | 章节切换、右侧面板、时间轴 |
| 详情 | 目录、代码块、图片查看器、上一篇/下一篇、导出 |
| 关于 | 三语内容回退、字数统计 |
| 公告 | 列表、弹窗 |
| 快捷链接 | 分类滚轮、卡片网格、移动端弹窗 |

移动端可跑：

```bash
node scripts/verify-detail-mobile.mjs --id <文章ID>
```

## 6. 文档与记录

- [ ] `更新日志.md` 增加条目（内容更新可归入 Changed / Added）。
- [ ] 结构或约定变化时更新 `docs/` 与 `AGENTS.md`。
- [ ] 重要决策补充 ADR。
- [ ] 需要公告时执行 `node scripts/generate.js "公告内容"`。

## 7. 部署

| 目标 | 操作 |
| --- | --- |
| GitHub Pages | 推送 `main` 或手动触发 `deploy-pages` 工作流 |
| 自建服务器 | 上传整个 `dist/`，保留 `blogs/` 与 `data/` |
| 回滚 | 重新部署上一个通过的构建产物 |

- [ ] 部署后访问首页与一篇文章，确认无缓存导致的旧资源混用。
- [ ] 若使用 CDN，刷新 `index.html` 与 `assets/` 的缓存策略。

## 8. 打标签（可选）

```bash
git tag -a v4.2.0 -m "YoungBlog 4.2.0"
git push origin v4.2.0
```

版本号与站点公告中的「制作者通讯」编号保持一致。
