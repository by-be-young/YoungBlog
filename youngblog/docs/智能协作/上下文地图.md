# 上下文地图

按任务类型列出**必读文件**。先读「必读」，再按需读「相关代码」。不要一次读完整个仓库。

## 1. 新增页面 / 功能

必读：

- `docs/指南/新增页面或功能.md`
- `src/router/index.js`
- `src/shared/stores/i18nStore.js`（只读结构，确认键命名）
- `src/app/App.vue`（页面名影响背景与萤火虫）

相关：`src/features/home/HomeView.vue`（作为页面写法参考）、`src/shared/layout/AppNavbar.vue`。
