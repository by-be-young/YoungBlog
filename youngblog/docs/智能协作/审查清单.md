# Agent 交付前自检

在宣布任务完成前，逐项确认。无法确认的项必须标注「未验证」，不得默认为通过。

## 1. 改动范围

- [ ] `git status` 中只有本任务相关文件。
- [ ] 没有修改 `dist/`、`node_modules/`、`blogs/.obsidian/workspace.json`。
- [ ] 没有批量格式化无关文件。
- [ ] 没有删除或移动用户内容（除非任务明确要求）。

## 2. 结构与导入

- [ ] 新文件在正确的 `features` / `shared` 层。
- [ ] 没有新增 `features` 之间的互相引用。
- [ ] 导入使用 `@/`，没有旧路径残留（`Grep` 确认）。
- [ ] 动态导入路径已同步修改。

## 3. 行为

- [ ] 页面在开发模式可打开，路由可直达与刷新。
- [ ] 涉及的交互（目录、代码块、搜索、习题、弹窗）手动点过。
- [ ] 空数据、404、加载失败时有合理回退。
- [ ] 定时器 / 监听器在卸载时清理。

## 4. 样式

- [ ] 三档宽度检查过。
- [ ] 没有新增全局 CSS 污染。
- [ ] `prefers-reduced-motion` 下仍可用。
- [ ] 移动端安全区（底部胶囊）未被遮挡。

## 5. 国际化

- [ ] 新增文案在 `zh` / `en` / `ja` 都存在。
- [ ] 没有硬编码用户可见中文。

## 6. 数据与构建

- [ ] `public/data/blogs.json` 的 diff 符合预期。
- [ ] `npm run build` 通过（或明确说明未运行及原因）。
- [ ] 涉及路径时验证过 `npm run build:github`。
- [ ] 新增图片已生成 WebP 并登记。

## 7. 文档

- [ ] 结构变化已更新 `docs/架构/模块地图.md` 与 `AGENTS.md`。
- [ ] 新行为已写入对应参考文档。
- [ ] 新陷阱已写入 `docs/运维/已知行为与陷阱.md`。
- [ ] `node scripts/check-docs.mjs` 通过。

## 8. 汇报

- [ ] 列出改动文件与目的。
- [ ] 列出实际运行的验证命令与结果。
- [ ] 明确列出未验证项与建议的后续验证。
- [ ] 没有把推测写成事实。

## 9. 禁止的「完成」表述

- 「应该可以」但没构建。
- 「样式已适配」但没看移动端。
- 「文档已更新」但没跑链接检查。
- 「不影响其他页面」但没有依据。
