# 故障排查

按「症状 → 优先检查 → 处理」组织。先确认问题发生在**开发**、**构建**还是**线上**。

## 1. 启动与构建

| 症状 | 优先检查 | 处理 |
| --- | --- | --- |
| `Unsupported engine` | `node -v` | 升级到 22.18+ 或 24.12+ |
| `npm ci` 失败 | 是否混用 pnpm/yarn、lock 文件是否冲突 | 删除 `node_modules` 后重试；不要手改 lock |
| `Cannot find module '@/...'` | 文件是否被移动、别名是否仍指向 `src` | 修导入；确认 `vite.config.js` 与 `jsconfig.json` |
| `generate.js` 报 YAML 错误 | 文章开头 `---` 是否闭合 | 补结束标记 |
| `postbuild` 提示找不到 `blogs/` | 命令是否在仓库根执行 | `cd` 到仓库根再构建 |
| 构建 OOM | 是否同时开着 dev server / 其他构建 | 关闭后重试；不要盲目加大内存 |

## 2. 开发环境

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 首页没有新文章 | dev 不跑 `generate.js` | `node scripts/generate.js` 后刷新 |
| 详情页 404 | `contentFile` 指向的文件不存在 | 检查路径与文件名大小写 |
| 修改 frontmatter 不生效 | 数据未重建 | 重新生成 `blogs.json` |
| 字体是系统默认 | `src/assets/fonts` 缺失或 CSS 路径变动 | 恢复字体与 `global.css` 的 `@font-face` |
| HMR 后样式错乱 | CSS 导入顺序被改动 | 恢复 `main.js` 的顺序 |
| 端口占用 | 5173 被其他进程使用 | 关闭进程或让 Vite 自动换端口 |

## 3. 页面运行

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 入场加载屏卡住 | 某张预载图 404 或解码失败 | 检查 `index.html` preload 与 `useEntryLoader` 清单 |
| 背景只有一张 / 不轮播 | `background-images.json` 为空属正常 | 回退默认图；若要自定义，见「已知行为」 |
| 图片全部裂开 | 部署在子路径但用了绝对 `/assets/...` | 统一走 `resolveUrl` / `assets/...` 相对写法 |
| Mermaid 不渲染 | 代码块语言不是 `mermaid` 或运行时加载失败 | 检查围栏标记；看控制台动态导入错误 |
| 公式显示为 `$...$` | KaTeX 动态导入失败 | 检查 `katex` 依赖与 CSP |
| 搜索不到正文 | `dist/blogs/` 缺失 | 重新构建并完整上传 |
| 页脚无访问量 | 无 `stats.json`（Pages 正常） | 属预期行为 |
| 语言切换后部分文案未变 | 三语词典缺键 | 补齐 `zh/en/ja` |

## 4. 部署

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 整站空白 | `base` 与部署路径不一致 | 用 `build:github` 或修改 base |
| 刷新详情页 404 | 路由被改成 History 模式 | 恢复 `createWebHashHistory` |
| 只有 HTML 没有资源 | 只上传了 `index.html` | 上传完整 `dist/` |
| 更新后仍是旧页面 | `index.html` 被缓存 | 配置 no-cache 或刷新 CDN |
| 字体 / 大图超时 | 服务器限制响应大小或带宽 | 检查 Nginx `client_max_body_size` 与压缩 |

## 5. 工具与脚本

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| `optimize:images` 不生成 | 新图未登记 `MANIFEST` | 在脚本中补一条 |
| `check:images` PSNR 很低 | 透明图未预乘 alpha（脚本已处理）或压缩过度 | 降低压缩强度或检查源图 |
| `verify-detail-mobile` 失败 | 无 Chromium、未构建、文章 ID 错误 | 先 `npm run build`，确认 `--id` |
| `check-docs` 报链接失效 | 文件改名后未更新引用 | 按输出逐个修正 |
| `lint` 改动大量文件 | `--fix` 自动修复 | 只提交与本次任务相关的 diff |

## 6. 排查顺序建议

1. 看浏览器控制台的第一条错误，而不是最后一条。
2. 确认请求 URL 是否缺少 base 前缀。
3. 确认 `dist/` 里是否真的存在该文件。
4. 用 `node scripts/preview-server.mjs` 复现，排除宿主服务器因素。
5. 最后才怀疑浏览器兼容性与缓存。
