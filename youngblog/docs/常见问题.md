# 常见问题

## 1. 这个项目是什么？

一个纯静态的个人博客：文章是 `blogs/` 下的 Markdown，Vue 3 + Vite 负责渲染，构建时生成索引 JSON。

## 2. 为什么文章目录就是分类？

`generate.js` 把 `blogs/` 的前三层目录写进 `tags`，首层决定首页「学习 / 娱乐」。
这样写作时不需要维护额外分类字段，移动目录即可调整分类。

## 3. 为什么改了正文，发布日期没变？

构建时会沿用旧 `blogs.json` 中同路径文章的日期，避免每次构建都让旧文章「变新」。
需要改日期就改 frontmatter 的 `date`。详见 [文章元数据参考](参考/文章元数据参考.md)。

## 4. 为什么重命名文章后旧链接打不开？

自动 ID 是 `contentFile` 路径的哈希。移动或重命名会换 ID。
需要稳定链接时，在 frontmatter 固定 `id`。

## 5. 为什么 `background-images.json` 是空的？

生成器扫描的是仓库根目录的 `assets/images/background`，该目录不存在，
因此前端回退到三张默认背景图。这是既有行为，详见
[已知行为与陷阱](运维/已知行为与陷阱.md)。

## 6. 为什么必须用 Hash 路由？

GitHub Pages 等静态托管无法为任意路径返回 `index.html`。
Hash 路由把路径放在 `#` 后，服务器只处理入口页，刷新不会 404。

## 7. `npm run dev` 为什么看不到新文章？

dev 模式不执行 `generate.js`。先运行 `node scripts/generate.js` 再刷新。

## 8. 部署后详情页空白，但首页正常？

多半是 `dist/blogs/` 没有上传。详情页通过 `contentFile` 拉取原始 Markdown，
该目录由 `postbuild.js` 复制产生。

## 9. 可以手动改 `public/data/blogs.json` 吗？

不建议。它是生成产物，下一次构建会被覆盖。
需要调整字段请改 frontmatter 或生成逻辑。

## 10. 为什么 `[task]` 块没有渲染？

结束标记必须是反斜杠形式 `[\task]`，不是 `[/task]`。
详见 [扩展语法参考](参考/扩展语法参考.md)。

## 11. 可以换成 History 路由吗？

除非托管方支持 SPA 回退（如 Nginx `try_files`），否则不要换。
换之前请先写 ADR 并验证刷新、深链接与子路径部署。

## 12. 为什么字体这么大？

站点使用约 18 MB 的书法字体，属于视觉设计的一部分。
替换时优先子集化或 WOFF2，并同步入场加载器的字体阶段。

## 13. 如何参与贡献？

先读 [贡献指南](../贡献指南.md)。代码改动需通过 lint 与构建；
内容投稿从 `blogs/模板/文章模板.md` 开始。

## 14. AI Agent 应该如何开始？

先读根目录 [AGENTS.md](../AGENTS.md)，再按
[上下文地图](智能协作/上下文地图.md) 选择必读文件。
