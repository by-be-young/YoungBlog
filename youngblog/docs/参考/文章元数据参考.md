# frontmatter 参考

文章头部用 `---` 包裹的 YAML 称为 frontmatter。`scripts/generate.js` 用
[gray-matter](https://github.com/jonschlinkert/gray-matter) 解析它，并写入 `blogs.json`。

## 1. 最小示例

```yaml
---
title: 并查集
date: 2026-03-12
---
```

## 2. 完整示例

```yaml
---
title: 编译实验-词法分析
date: 2026-10-01
excerpt: 2421 编译实验作业——词法分析实验心得
type: 系统笔记
series: 编译原理
chapter: 2 - 实验
order: 2
recommended: true
---
```

## 3. 字段表

| 字段 | 类型 | 必填 | 默认 / 回退 | 说明 |
| --- | --- | --- | --- | --- |
| `title` | string | 建议 | 文件名（不含扩展名） | 文章标题；空字符串视为缺失 |
| `date` | string \| Date | 建议 | 旧记录日期 → 文件 mtime | 支持 `YYYY-MM-DD` 或 `YYYY-MM-DD HH:mm:ss`（空格会自动换成 `T`） |
| `excerpt` | string | 否 | 正文首段有效文本，截断 80 字符 | 首页卡片摘要 |
| `type` | string | 否 | `null` | 自定义分类标签，展示在卡片/详情页 |
| `series` | string \| string[] \| object | 否 | `null` | 系列名；数组取第一个有效项，对象取 `title` 或 `name` |
| `order` | number \| string | 否 | `null` | 无 `chapter` 时的系列内排序，取整 |
| `chapter` | string | 否 | `null` | `N - 标题` 或纯标题；决定系列内顺序 |
| `recommended` / `推荐` | boolean | 否 | `false` | 首页推荐位 |
| `id` | number | 否 | 路径哈希 | 手动指定文章 ID，一般不要使用 |

## 4. 日期规则

1. frontmatter 中有合法 `date` → 使用它。
2. 没有 → 复用**上一次** `public/data/blogs.json` 中同一 `contentFile` 的日期。
3. 仍没有 → 使用文件修改时间。

这样重复构建不会让旧文章「变新」。但副作用是：**只改 frontmatter 日期**才会改排序，
修改正文不会自动更新发布日期。若需要「最后编辑」时间，生成器会在检测到文件修改时写入
`lastEditedDate`。

## 5. `chapter` 的解析

| 写法 | `order` 解析结果 | 排序 |
| --- | --- | --- |
| `3 - 内存管理` | 3 | 有章节组内按 3 升序 |
| `3-内存管理` | 3 | 同上（空格可有可无） |
| `实验` | `Infinity` | 有章节但无序号，排在有编号的章节之后 |
| 不写 | — | 排在所有有章节文章之后，按 `order` / 日期 |

系列排序完整规则见 [data-flow](../架构/数据流.md)。

## 6. 标签来自目录，不来自 frontmatter

`tags` 由 `blogs/` 下的相对路径前 3 层生成，例如：

```text
blogs/三上/编译/文法与词法/词法分析.md
→ tags: ["三上", "编译", "文法与词法"]
→ category: "学习"（首层命中 三上）
```

因此：

- 想改标签，移动目录，而不是加 `tags` 字段。
- 移动目录会改变 `contentFile`，进而改变自动生成的 `id`。

## 7. ID 与链接稳定性

- 没有 frontmatter `id` 时，ID = FNV-1a(`contentFile` 路径) 的 32 位无符号整数。
- 详情页 URL 为 `/blog/<id>`。
- **重命名或移动文章 = 换 ID = 旧链接失效。** 如需保持链接，请在 frontmatter 固定 `id`。
- ID 冲突时生成器会 `+1` 直到唯一，因此手动写 `id` 仍可能被微调。

## 8. 常见错误

| 错误 | 后果 | 处理 |
| --- | --- | --- |
| 开头 `---` 未闭合 | 整篇被当作正文，元数据丢失 | 补结束 `---` |
| `date: 2026/10/01` | 部分浏览器解析失败，回退到 mtime | 改成 `2026-10-01` |
| `tags: [...]` 想手动加标签 | 无效，标签仍由目录生成 | 调整目录 |
| `series: ""` | 视为无系列 | 删除或填有效名称 |
| 在 `blogs/` 根放草稿 | 被当成正式文章收录 | 移到 `blogs/模板/` 或其他非文章目录 |
