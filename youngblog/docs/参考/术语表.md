# 术语表

| 术语 | 含义 | 位置 |
| --- | --- | --- |
| 学年层 | `blogs/` 第一层目录，如 `二上` / `三上` / `文学` | `blogs/` |
| 主题层 | 第二层目录，通常是课程名，如 `编译` / `操作系统` | `blogs/` |
| 小节层 | 第三层目录，如 `文法与词法` / `内存管理` | `blogs/` |
| 标签（tags） | 由前三层目录自动生成，不接受手动 frontmatter | `generate.js` |
| 首页分类 | 「学习」或「娱乐」，由首层标签决定 | `generate.js` / `blogStore` |
| 系列（series） | 跨文章的逻辑集合，如「编译原理」 | frontmatter `series` |
| 章（chapter） | 系列内的分组，`N - 标题` 形式带排序 | frontmatter `chapter` |
| 节 / 文章 | 系列内的单篇内容 | `blogs/**.md` |
| 推荐 | 首页推荐位标记 | `recommended` / `推荐` |
| 快捷链接 | 友链、常用工具、学习资源的卡片集合 | `public/data/quick-links.json` |
| 友链 | 快捷链接中的 `friends` 分类 | 同上 |
| 云图 | 分类页的全屏筛选交互，云朵代表三级分类 | `CategoriesView.vue` |
| 卡片堆 | 分类页斜向排列、选中居中的卡片列表 | `CategoriesView.vue` |
| 入场加载屏 | 首屏加载动画，预载字体、数据、图片 | `EntrySplash.vue` / `useEntryLoader.js` |
| 揭幕 | 入场加载屏结束、页面内容开始播放动画的时刻 | `App.vue` |
| 沉浸阅读 | 隐藏干扰、加宽正文的阅读模式 | `settingsStore.isImmersive` |
| 习题模式 | 控制 `[task]` 习题块显示方式的设置 | `settingsStore.exerciseMode` |
| 代码块模式 | `peek`（半展开）/ `collapse` / `expand` | `settingsStore.codeMode` |
| 制作者通讯 | 站点公告的版本化标题体系 | `announcements.json` |
| 门帘 | 入场加载屏的俗称（遮住首屏的层） | 内部称呼 |
| 子路径部署 | 站点部署在 `/YoungBlog/` 而非根路径 | `mode=github` |
| 内容文件 | 相对仓库根的 Markdown 路径，存于 `contentFile` | `blogs.json` |
| 生成产物 | `generate.js` 写出的 JSON，不手工编辑 | `public/data/` |
| 稳定 ID | 由内容文件路径哈希得到的数字 ID | `generate.js` |
| 旧链接兼容 | `/blog-detail.html?id=xxx` 重定向到 `/blog/xxx` | `router/index.js` |
| 马卡龙色系 | 搜索面板与列表标记的低饱和粉 / 薄荷 / 淡紫 | `search.css` |
| 探针 | 验证脚本注入页面、把几何信息写回 DOM 的脚本 | `verify-detail-mobile.mjs` |
