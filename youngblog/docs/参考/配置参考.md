# 配置参考

## 1. `package.json`

| 字段 | 值 | 说明 |
| --- | --- | --- |
| `type` | `module` | 全仓库使用 ESM |
| `engines.node` | `^22.18.0 \|\| >=24.12.0` | 低于此版本 Vite 8 无法运行 |
| `scripts.build` | `generate.js → vite build → postbuild.js` | 内容数据与站点一起产出 |
| `scripts.build:github` | 同上，`--mode github` | 切换 base |

新增脚本时保持「一个命令做一件事」，不要在一个脚本里混合内容生成与打包。

## 2. `vite.config.js`

```js
export default defineConfig(({ command, mode }) => {
  let base = '/'
  if (mode === 'github') base = '/YoungBlog/'
  return {
    plugins: [vue()],
    base,
    resolve: { alias: { '@': path.resolve(__dirname, './src') } },
    server: { port: 5173, open: true },
    build: {
      outDir: 'dist',
      assetsDir: 'assets',
      rollupOptions: {
        output: {
          manualChunks(id) {
            if (/node_modules\/(vue|vue-router|pinia)\//.test(id)) return 'vendor'
          }
        }
      }
    }
  }
})
```

要点：

- `base` 只由 `mode` 决定，没有环境变量开关。若仓库名不是 `YoungBlog`，
  必须改这里的字符串，否则 GitHub Pages 下所有资源 404。
- `@` 别名指向 `src`，`jsconfig.json` 仅为编辑器提供同一映射。
- `vendor` 分包只包含框架三件套；其余大库靠动态导入自然分块。

## 3. `jsconfig.json`

```json
{
  "compilerOptions": { "paths": { "@/*": ["./src/*"] } },
  "exclude": ["node_modules", "dist"]
}
```

Vite 不读取它，但 VS Code / WebStorm 依赖它做跳转与补全。
修改别名时必须同时改 `vite.config.js` 与本文件。

## 4. ESLint

`eslint.config.js`（Flat Config）：

- 检查 `**/*.{vue,js,mjs,jsx}`；
- 忽略 `dist` / `dist-ssr` / `coverage`；
- 浏览器全局变量；
- `scripts/**` 追加 Node 全局变量；
- 组合 `@eslint/js`、`eslint-plugin-vue` 的 `flat/essential`、`eslint-plugin-oxlint`
  与 `eslint-config-prettier`。

`npm run lint:eslint` 带 `--fix` 与 `--cache`，缓存文件 `.eslintcache` 已被忽略。

## 5. oxlint

`.oxlintrc.json` 开启 `correctness` 类规则与 `eslint` / `unicorn` / `oxc` / `vue` 插件。
`npm run lint:oxlint` 先跑 oxlint，再交给 ESLint，两者都带 `--fix`。

## 6. Prettier

`.prettierrc.json`：

```json
{ "semi": false, "singleQuote": true, "printWidth": 100 }
```

`npm run format` 只格式化 `src/`，避免误改 `blogs/` 内容与 `public/data`。

## 7. EditorConfig

`.editorconfig` 对 JS / Vue / CSS 等统一：UTF-8、2 空格、LF、文件末尾换行、去除行尾空白、行宽 100。
它先于 Prettier 生效，编辑器应优先读取。

## 8. `.gitattributes`

```text
* text=auto eol=lf
```

全仓库强制 LF。Windows 下若看到整文件 diff，通常是换行被改成了 CRLF。

## 9. `.nvmrc`

```text
22.18.0
```

仅供 `nvm use` / `fnm use` 使用；实际允许范围以 `package.json` 的 `engines` 为准。

## 10. 环境与模式

| 项 | 取值 | 来源 |
| --- | --- | --- |
| 站点根路径 | `/` 或 `/YoungBlog/` | `mode=github` |
| 资源前缀 | `import.meta.env.BASE_URL` | 所有请求经 `resolveUrl` |
| 开发端口 | 5173 | `server.port` |
| 预览端口 | 4173 | `vite preview` / 预览服务器默认值 |

仓库没有 `.env` 文件，也没有运行时环境变量注入；所有部署差异都收敛在 `base`。

## 11. 新增配置的规则

1. 优先修改现有配置文件，不新增平行配置。
2. 修改 `base`、别名或输出目录时，同步本文档与 `docs/架构/构建管线.md`。
3. 不引入会改写 `blogs/` 的格式化或 lint 规则。
4. CI 使用的命令必须与本地一致，避免「本地过、CI 挂」。
