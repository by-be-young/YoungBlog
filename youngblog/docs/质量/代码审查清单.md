# 代码审查清单

按影响面从大到小排列。审查者可直接复制为 PR 评论模板。

## 1. 行为与范围

- [ ] 改动与 PR 描述一致，没有夹带无关重构。
- [ ] 没有改变既有页面行为（除描述中明确说明）。
- [ ] 没有删除或重命名用户内容（`blogs/`）与生成数据（`public/data/`）。
- [ ] 没有提交 `dist/`、`node_modules/`、临时截图、个人配置。

## 2. 结构

- [ ] 新文件放在正确的功能域或 `shared` 层。
- [ ] `features` 之间没有新增互相引用。
- [ ] `shared` 没有反向依赖 `features`。
- [ ] 导入使用 `@/` 别名，没有新增深相对路径。
- [ ] 新增目录带 `README.md`。

## 3. 正确性

- [ ] 边界条件处理（空数组、缺失字段、404、空字符串）。
- [ ] 异步失败有回退，不导致白屏。
- [ ] 定时器、事件监听、observer 在卸载时清理。
- [ ] 没有依赖数组顺序或对象键顺序的隐式假设。
- [ ] 路由 name 与 `App.vue` 的页面判断保持一致。

## 4. UI 与样式

- [ ] 桌面 / 平板 / 手机三档验证。
- [ ] 没有新增全局 CSS 污染。
- [ ] 颜色、圆角、阴影复用现有体系。
- [ ] 动效在 `prefers-reduced-motion` 下可用。
- [ ] 弹窗能用 Esc 关闭，焦点可返回。

## 5. 国际化

- [ ] 新增文案在 `zh` / `en` / `ja` 三处都有。
- [ ] 没有硬编码用户可见中文。
- [ ] 变量占位符正确替换。

## 6. 数据与构建

- [ ] `blogs.json` 的 diff 只包含预期文章。
- [ ] 新增图片已生成 WebP 并登记清单。
- [ ] 子路径构建（`build:github`）可用。
- [ ] `dist/blogs/` 相关逻辑未被破坏。

## 7. 文档

- [ ] 结构或行为变化已更新 `docs/`。
- [ ] 重要决策有 ADR。
- [ ] 文档链接有效（`node scripts/check-docs.mjs`）。
- [ ] `AGENTS.md` 中的命令与约束仍然准确。

## 8. 验证

- [ ] `npm run lint` 通过。
- [ ] `npm run build` 通过。
- [ ] 涉及 UI 的改动附前后对比或复现步骤。
- [ ] 涉及移动端的改动附设备 / 视口说明。

## 9. 评审结论

| 结论 | 含义 |
| --- | --- |
| Approve | 可合并 |
| Approve with comments | 小问题，修改后可直接合并 |
| Request changes | 存在行为、结构或安全问题，必须修改 |

审查者应指出「问题 + 原因 + 建议」，而不是只给结论。
