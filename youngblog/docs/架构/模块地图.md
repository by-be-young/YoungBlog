```text
youngblog/

```

## 3. 职责速查

| 模块 | 单一职责 | 不该做的事 |
| --- | --- | --- |
| `app/App.vue` | 组合壳层、背景轮播、路由过渡状态 | 不承载具体页面业务 |
| `router/index.js` | 路由与页面标题 | 不做数据请求 |
| `features/*/View.vue` | 页面编排与页面级状态 | 不直接操作别的 feature 的 DOM |
| `features/*/components` | 该页面私有的展示与交互 | 不放跨页面复用逻辑 |
| `shared/components` | 全局弹窗与通用 UI | 不依赖具体路由 |
| `shared/layout` | 导航与页脚 | 不承载页面内容 |
| `shared/composables` | 可复用行为（渲染、目录、加载器…） | 不定义全局单例状态 |
| `shared/stores` | 全局状态与数据获取 | 不做 DOM 操作 |
| `shared/utils` | 纯函数与轻量封装 | 不产生副作用 |
| `assets/styles` | 变量、基线、断点 | 不放单组件样式 |

## 4. 关键文件

| 文件 | 说明 |
| --- | --- |
| `src/main.js` | 全局 CSS 的导入顺序在此固定，调整顺序会改变层叠结果 |
| `src/app/App.vue` | 定义 `body.home` 类、背景图 fallback、首次交互初始化音频 |
| `src/shared/composables/useEntryLoader.js` | 入场阶段权重、默认背景图、预载清单 |
| `src/shared/composables/useMarkdown.js` | Markdown 扩展语法的唯一入口 |
| `src/shared/composables/useToc.js` | 目录生成、滚动同步与进度 |
| `src/shared/stores/blogStore.js` | 站点唯一的数据入口 |
| `src/shared/utils/url.js` | 所有资源 URL 的 base 前缀处理 |

## 5. 依赖方向示意

```text
main.js
 ├─ app/App.vue ──────────────┐
 ├─ router ── features/*      │
 │             └─ shared ─────┘
 └─ assets/styles
```

- `features` → `shared`：允许。
- `shared` → `features`：禁止（`about` 复用 `blog-detail/BlogContent` 是唯一例外）。
- `features` → 另一个 `features` 的视图：禁止。

## 6. 与旧结构的对照

| 旧路径 | 新路径 |

| `src/App.vue` | `src/app/App.vue` |
| `src/views/*.vue` | `src/features/<feature>/*View.vue` |
| `src/components/home/*` | `src/features/home/components/*` |
| `src/components/blog-detail/*` | `src/features/blog-detail/components/*` |
| `src/components/common/*` | `src/shared/components/*` |
| `src/components/layout/*` | `src/shared/layout/*` |
| `src/composables/*` | `src/shared/composables/*` |
| `src/stores/*` | `src/shared/stores/*` |
| `src/utils/*` | `src/shared/utils/*` |
| `src/css/*` | `src/assets/styles/*`（`style.css` → `global.css`） |
| `src/style.css` | `src/assets/styles/base.css` |
| `src/fonts/*` | `src/assets/fonts/*` |
