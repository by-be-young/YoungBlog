# 样式与主题

站点不使用 UI 框架，全部样式为原生 CSS：少量全局样式 + 组件内 `scoped` 样式。

## 1. 全局样式的导入顺序

`src/main.js` 中的顺序是层叠结果的一部分，**不要随意调整**：

```js
import './assets/styles/base.css'        // 重置与基础排版
import '@fortawesome/fontawesome-free/css/all.min.css'
import './assets/styles/global.css'      // 变量、导航、容器、滚动条、页面过渡
import './assets/styles/butterfly.css'   // 按钮与装饰
import './assets/styles/responsive.css'  // 全局断点
import './assets/styles/search.css'      // 搜索面板配色
import 'highlight.js/styles/atom-one-dark.css'
import 'katex/dist/katex.min.css'
```

后导入的规则会覆盖先导入的同等优先级规则；把 `responsive.css` 提前会导致断点失效。

## 2. 文件职责

| 文件 | 内容 |
| --- | --- |
| `base.css` | `*` 重置、`body` 字体与底色、`#app`、链接、`.container`、标题字重 |
| `global.css` | 设计变量、字体 `@font-face`、导航栏、页面过渡、滚动条、浮动按钮 |
| `butterfly.css` | `.btn` 等渐变按钮 |
| `responsive.css` | 首页 / 归档 / 分类等全局断点（≤1100px 起） |
| `search.css` | 马卡龙色系搜索面板与高亮 |
| `features/blog-detail/components/blog-content.css` | 文章正文全部元素样式（`<style scoped src>`，用 `:deep()` 命中 `v-html`；`--md-*` 变量定义在此） |

## 3. 字体

`global.css` 通过两组 `@font-face` 加载 `../fonts/canger-ui.woff2` 与 `../fonts/canger-content.woff2`（相对 `assets/styles/`），
并以变量 `--webfont-name` 暴露给其他规则。首屏只加载 UI 子集约 408 KB，正文子集约 255 KB 在文章页按需加载。

- 不要把字体移到 `public/`：`src/assets` 下的资源会参与构建与缓存命名。
- 更换字体需同步 `index.html` 的 preload 策略与 `useEntryLoader` 的字体阶段。

### 3.1 根字号与等比缩放

`global.css` 的 `html` 根字号是全站唯一缩放入口：

```css
font-size: clamp(13.5px, calc(0.443vw + 10.32px), 16px);
```

- 720px 及以下固定 13.5px 下限，向上连续增大，1280px 起恢复 16px。768px 约 13.7px，829px 约 14px，1024px 约 14.9px。
- 所有字号必须用 `rem` / `em`。`rem` 字号、图标字号与 `rem` 间距会同比缩小；`px` 只用于需要保持物理尺寸的触控区、边框和媒体。
- 新增组件不得写 `px` 字号，否则小屏不会跟随根字号缩小。
- 图标按钮的点击区域可继续用 `px` 保持 ≥44px，不必为了视觉等比牺牲可点击性。

## 4. CSS 变量

核心变量定义在 `global.css` 的 `:root`：

| 变量 | 用途 |
| --- | --- |
| `--webfont-name` | 书法字体族名 |
| `--primary-color` / `--secondary-color` | 主色与辅助色，用于渐变按钮 |
| `--macaron-*` | 搜索面板的马卡龙配色（`search.css`） |
| `--notice-*` | 公告 / 设置 / 悬浮控制坞的「纸面 + 黄绿」主题（见下） |

`--notice-*` 是悬浮组件与公告页的语义色板，组件里只引用变量、不写色值：

| 变量 | 用途 |
| --- | --- |
| `--notice-accent-100…-400` | 黄绿由浅到深的底色阶（选中态、标签、渐变） |
| `--notice-accent` / `-strong` / `-deep` | 主黄绿 / 描边与图标 / 文字与标题 |
| `--notice-gold` / `--notice-gold-soft` | 顶栏与色带的暖金起点 |
| `--notice-accent-wash` / `-veil` | 黄绿的透明铺底（wash 更淡）/ 描边与滑块轨道 |
| `--notice-glow` | 黄绿投影 |
| `--notice-paper` / `-solid` / `-muted` | 纸面半透明 / 实色（需要挡背景时）/ 更淡的次级底 |
| `--notice-ink` / `-soft` / `-faint` | 主文字 / 次级文字 / 辅助说明 |
| `--notice-line` / `-strong` | 细分隔线 / 需要更明显的边框 |
| `--notice-on-accent` | 黄绿实底上的文字色 |
| `--notice-scrim` | 弹窗遮罩 |
| `--notice-inset` | 卡片顶部的 1px 内高光 |
| `--notice-shadow` / `--notice-shadow-soft` | 悬浮卡片的投影 / 轻投影 |

新增变量放在 `:root`，命名使用 `--kebab-case`，并在本文档登记用途。

## 5. 布局约定

- `body` 上由 `App.vue` 维护 `home` 类：首页的侧栏折叠、栅格列数依赖它。
- 归档 / 分类 / 快捷链接 / 公告页给背景加 `is-frosted`（毛玻璃）；系列页用 `is-series`（强蒙版）。
- 页面级容器统一使用 `.container`（最大宽度 1200px）。
- 大型页面（归档、分类、系列、快捷链接）把布局样式写在自身 `<style scoped>` 中，
  因为这些布局高度定制，放进全局会造成互相污染。

## 6. 响应式

- 全局断点：`1100px`（首页侧栏隐藏、导航转抽屉）、`768px` / `480px`（页面局部）。
- 各视图可在 `scoped` 中追加断点，但同一断点值应在全站保持一致。
- 移动端必须验证：导航抽屉、详情页目录、沉浸模式退出胶囊、习题卡片。
  可用 `node scripts/verify-detail-mobile.mjs --id <id>` 做几何断言。

## 7. 样式编写规则

1. 组件样式默认 `scoped`；只有确实需要影响子组件内部结构时才用 `:deep()`。
2. 不新增全局选择器，除非它服务多个功能域，并放在 `assets/styles/`。
3. 类名使用 `kebab-case`；页面级前缀（`blog-` / `series-` / `quick-links-`）避免冲突。
4. 不使用内联样式表达主题色；内联样式仅用于运行时计算值（如背景图 URL、随机色）。
5. 动画需考虑 `prefers-reduced-motion`：入场加载器已在减少动效时跳过。
6. 不引入新的 CSS 预处理器或 UI 库，除非有 ADR 说明。

## 8. 配色与视觉基调

- 浅色卡片 + 低饱和渐变（粉 / 薄荷 / 淡紫）是站点主视觉。
- 深色底（`base.css` 的 `#0a0a0a`）只在背景层与部分浮层使用。
- 新增页面应复用现有渐变与圆角语言，避免引入高饱和纯色块。
- 卡片圆角、阴影与模糊值请从现有页面复制，不要另造一套尺度。

### 8.1 正文内容组件

正文样式集中在 `blog-content.css`，按「排印化组件」组织：正文、引用与代码块保持细线轻装饰；标题统一使用低饱和色底板 + 左侧强调条（h1 蓝、h2 绿、h3 琥珀、h4 淡紫），文字色沿用当前更深的一版色值，不再回到旧版高饱和文字色。

- 颜色统一走 `--md-ink` / `--md-paper` / `--md-line` / `--md-h1..h4`（text + accent + wash）/ `--md-answer` / `--md-wrong` / `--md-select`，改配色只改变量，不在各规则里写死。
- 例题块为「悬浮题头 → 题干软纸面板 → 独立选项卡 → 操作条 → 答案解析」：题头 `.md-task-head` 绝对定位在卡片左上，含书签图标、`.md-task-tag` / `.md-task-index` / `.md-task-type`，编号由 `annotateTaskLabels` 回填，题型与统计由 `useAnswer` 的 `syncTaskMeta` / `updateTaskStats` 写入。
- 选项以独立圆角卡片纵向排列（容器 `gap: 9px`），单选圆键、多选六边形键；文章里常见的「一行一个 `[options]…[\options]`」仍由 `mergeOptionGroups` 合并进第一个 `.md-options` 容器，但视觉上保持一张张选项卡，不排成表格。
- 表格用 `.md-table-wrap` 承载横向滚动，`table` 为 `width: max-content; min-width: 100%`；不要改回 100% 宽，否则宽表会逐字换行。

## 9. 修改样式的验收

- 桌面（≥1280px）、平板（768–1100px）、手机（≤480px）三档截图对比。
- 检查背景蒙版、导航抽屉、页脚渐变在三种宽度下是否溢出。
- 检查 `prefers-reduced-motion` 下是否仍有必要的功能反馈。
