# 状态管理

站点使用 Pinia 的 Setup Store（`defineStore('id', () => {...})`），全部位于
`src/shared/stores/`。Store 只负责状态与数据获取，DOM 操作放在组合式函数或组件中。

## 1. Store 一览

| Store | 文件 | 状态 | 主要 API | 持久化 |
| --- | --- | --- | --- | --- |
| `blog` | `blogStore.js` | `blogs` / `isLoading` / `error` | `fetchBlogs` / `getBlogById` / `getBlogsBySeries` / `getRecentUpdates` | 否（内存缓存） |
| `i18n` | `i18nStore.js` | `lang` + 三语词典 | `t` / `setLang` / `getLang` / `currentTranslations` | `localStorage: site_language` |
| `settings` | `settingsStore.js` | `isImmersive` / `isWide` / `exerciseMode` / `codeMode` | `toggleImmersive` / `setExerciseMode` / `setCodeMode` | 否（会话内） |
| `music` | `musicStore.js` | `audio` / `currentTrack` / `isPlaying` / `volume` | `initAudio` / `togglePlay` / `seek` / `setVolume` | 否 |
| `background` | `backgroundStore.js` | `images` / `currentIndex` | `setImages` / `startSlideshow` / `stopSlideshow` | 否 |
| `counter` | `counter.js` | `count` | `increment` | 否（模板遗留，未被页面使用） |

## 2. blogStore 是唯一数据入口

```text
fetchBlogs()
  ├─ 已加载（blogs.length > 0）→ 直接返回，避免重复请求
  ├─ GET resolveUrl('/data/blogs.json')
  ├─ 非数组 → 抛错
  └─ catch → blogs = []（页面不崩溃，仅显示空态）
```

派生数据：

| 计算属性 / 方法 | 依据 |
| --- | --- |
| `tags` | 所有文章 `tags` 去重 |
| `seriesList` | 按 `series` 分组并按日期升序 |
| `recommendedBlogs` | `recommended === true` |
| `latestBlogs` | 日期倒序前 6 篇 |
| `getCategoryKey` | 优先 `blog.category`，否则看首标签是否属于 `二上/二下` |
| `getRecentUpdates` | 学习、娱乐各取最新一篇 |

> 注意：`generate.js` 判定「学习」的首层标签集合比 `blogStore` 的兜底集合更大
> （含 `三上/三下/四上/四下/大三`）。由于生成数据总带 `category` 字段，
> 正常情况下以 `category` 为准；仅当数据缺失时才可能不一致。见
> [known-quirks](../运维/已知行为与陷阱.md)。

## 3. i18n

- 词典在 `i18nStore.js` 内以 `translations = { zh, en, ja }` 维护。
- `lang` 初始化读取 `localStorage.site_language`，默认 `zh`。
- `setLang` 会写回 `localStorage` 并更新 `document` 语言相关行为。
- 模板中使用 `t('key')` 或 `currentTranslations.key`。
- 新增文案必须同时补齐三种语言；缺失键会在界面上显示为 `undefined`。

命名约定：

| 前缀 | 场景 |
| --- | --- |
| `home_` / `archive_` / `series_` / `quick_links_` | 页面文案 |
| `settings_` | 设置与音乐 |
| `search_` | 搜索面板 |
| `blog_` | 详情页通用 |
| `answer_` / `task_` | 习题交互 |

## 4. settingsStore

| 字段 | 取值 | 影响 |
| --- | --- | --- |
| `isImmersive` | `boolean` | 详情页宽屏 / 沉浸阅读 |
| `isWide` | `boolean` | 与沉浸模式联动，进入沉浸时置 `true` |
| `exerciseMode` | `hide` / `collapse` / `practice` / `expand` | 习题块显示方式 |
| `codeMode` | `peek` / `collapse` / `expand` | 代码块默认展开程度（Mermaid 只有展开/收起） |

`useSettings.apply(contentEl)` 将上述模式落到 DOM：切换 `practice-mode` 类、
显隐 `.md-task`、点击答案折叠按钮、调用 `useCodeBlock.setState`。

## 5. musicStore

- `audio` 为 `HTMLAudioElement`，`loop = true`，默认音量 `0.2`。
- 浏览器禁止无交互自动播放，因此 `initAudio()` 必须由首次 `click` / `keydown` 触发
  （`App.vue` 注册一次性监听）。
- `loadedTrack` 记录实际加载的曲目名，避免 URL 编码导致的重复加载。
- 播放失败（文件缺失）只重置状态，不弹错误。

## 6. backgroundStore 与 App 的分工

- `App.vue` 负责拉取 `background-images.json`、维护本地 `currentBgIndex` 与 5 秒轮播。
- `backgroundStore.setImages()` 也会启动自己的定时器，但当前页面渲染使用的是
  `App.vue` 的本地索引。修改轮播逻辑时注意两处不要重复推进。
- 清单为空时统一回退 `DEFAULT_BACKGROUND_IMAGES`（`useEntryLoader` 导出）。

## 7. 本地持久化清单

| 键 | 写入方 | 用途 |
| --- | --- | --- |
| `site_language` | `i18nStore` | 记住界面语言 |
| `yb-checklist:<blogId>` | `useChecklist` | 记住任务清单勾选状态 |

除以上两项外，刷新页面即重置。若新增持久化，请在此表登记并说明清理方式。

## 8. 新增 Store 的规则

1. 使用 Setup Store，返回对象显式列出 state / getters / actions。
2. 不在此层做 `document.querySelector` 等 DOM 操作。
3. 跨 Store 依赖只允许「读」，避免循环调用。
4. 网络请求集中在 Store 或 `useEntryLoader`，组件不直接 fetch 站点数据
   （详情页与 about 的 Markdown 文本除外）。
5. 新增持久化键必须带前缀（`yb-` / `site_`），并在本文档登记。
