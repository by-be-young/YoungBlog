# 路线图

本文记录**候选方向**，不是承诺。优先级会随内容更新与实际使用反馈调整。
已完成版本见 [更新日志](../../更新日志.md)。

## 1. 近期候选

### 内容与阅读

- [ ] 首页「最近更新系列」卡片：展示最近变动的系列与最新章节。
- [ ] 移动端习题卡片进一步压缩，减少长题干的横向滚动。
- [ ] 文章内跨文章引用（当前只支持 `[[#当前标题]]`）。
- [ ] 阅读进度在系列文章间延续。

### 性能与体积

- [ ] 字体子集化或转 WOFF2，降低首屏最大的单文件。
- [ ] 首屏图片进一步压缩，评估 AVIF。
- [ ] 搜索正文改为构建期索引，减少逐篇 fetch。

### 工程与质量

- [ ] 为 `generate.js` 的归一化逻辑补单元测试（Vitest）。
- [ ] 用 Playwright 覆盖「首页 → 详情 → 目录 → 搜索」主路径。
- [ ] 视觉回归基线（关键页面三档宽度）。
- [ ] 统一弹窗的焦点陷阱实现。

### 文档与协作

- [ ] 文档链接与命令纳入 CI（已提供 `check-docs.mjs`，待扩展更多规则）。
- [ ] 为每个 ADR 增加「失效条件」字段。
- [ ] 内容贡献模板的多语言说明。

## 2. 明确不做

- 在线编辑器 / CMS。
- 账号、评论、点赞等需要后端的状态系统。
- 把 Hash 路由改成 History 路由（除非托管方支持 404 回退）。
- 引入大型 UI 框架替换现有原生样式。

## 3. 评估原则

| 维度 | 问题 |
| --- | --- |
| 用户价值 | 是否改善阅读、检索或写作效率 |
| 成本 | 是否引入新依赖、新服务或长期维护负担 |
| 风险 | 是否影响既有视觉、链接或部署路径 |
| 可回滚 | 出问题时能否快速退回 |

## 4. 提需求的方式

在 Issue 中说明：使用场景、期望结果、可接受的取舍。
涉及架构变化的，先写 ADR 草案再实现。
