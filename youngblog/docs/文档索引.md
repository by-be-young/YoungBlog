# YoungBlog 文档中心

本目录是项目的长期知识库。文档与代码同仓维护：结构、命令或约定变化时，同步更新对应文档。
描述性文档使用中文文件名；`README.md`、`AGENTS.md`、`CLAUDE.md` 为工具约定的英文入口。

## 建议阅读顺序

1. 初次接触：[README](../README.md) → [架构总览](架构/架构总览.md) → [模块地图](架构/模块地图.md)
2. 准备开发：[本地开发](指南/本地开发.md) → [编码规范](质量/编码规范.md)
3. 准备写作：[内容工作流](指南/内容工作流.md) → [文章元数据参考](参考/文章元数据参考.md)
4. 准备发布：[构建管线](架构/构建管线.md) → [部署指南](运维/部署指南.md) → [发布检查清单](指南/发布检查清单.md)
5. 使用 AI Agent：[AGENTS.md](../AGENTS.md) → [AI 协作指南](智能协作/协作指南.md)
