# 0004 · 构建时生成索引 JSON

- 状态：已采纳

## 背景

前端需要文章列表、标签、系列、推荐等聚合信息。若在运行时扫描目录或逐篇解析 frontmatter，
既无法在浏览器中完成（没有文件系统），也会造成大量请求。

## 决策

`scripts/generate.js` 在构建前扫描 `blogs/`，输出：

- `public/data/blogs.json`：全量文章索引
- `public/data/series.json`：系列聚合
- `public/data/background-images.json`：背景清单（当前为空）
- `public/data/announcements.json`：仅在命令行传入公告时追加

前端只 fetch 这些 JSON，详情页再按 `contentFile` 取单篇 Markdown。

## 后果

- 内容变更必须重新生成索引，`dev` 模式不会自动执行。
- 生成器与前端对字段的理解必须一致（分类、排序、日期）。
- `blogs.json` 是构建产物，手工修改会被覆盖。
- 索引文件随文章数增长，需要关注体积。

## 备选

- 运行时解析：浏览器无法访问文件系统，排除。
- 预渲染每篇文章为 HTML：可作为未来优化，但当前交互依赖原始 Markdown。

## 失效条件

文章数量达到数千篇、索引体积影响首屏时，应改为分片索引或搜索服务。
