# 更新日志

格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号沿用站点公告中的命名。

## [Unreleased]

### Added

- 新增 `docs/` 文档体系：架构、指南、参考、运维、质量、ADR 与 AI 协作分册。
- 新增 `AGENTS.md`、`CLAUDE.md`、`.github/copilot-instructions.md`、`.cursor/rules/` 等 Agent 协作配置。
- 新增 GitHub Issue / PR 模板、CI 工作流、Dependabot 配置。
- 新增 `blogs/模板/` 写作模板与文章骨架。
- 新增各模块 `README.md` 与文档链接检查脚本。

### Changed

- 重构 `src/` 目录：`views` + `components` 拆分为 `features/`（按功能域）与 `shared/`（跨域复用）；
  `composables`、`stores`、`utils` 收入 `shared/`；`css`、`fonts`、根级 `style.css` 收入 `assets/`。
- `main.js` 与路由的导入路径同步调整，站点运行行为与视觉不变。

### Fixed

- 修正文档中与实现不一致的路径引用（`src/css/` → `src/assets/styles/`）。
- 修复 Windows + Node 22 下 `postbuild.js` 复制含中文目录崩溃的问题（改用逐层复制）。
- lint 忽略 `blogs/**`，避免扫描 Obsidian 插件与主题脚本。

## [4.1.0] - 2026-09-10

### Changed

- 系列界面整页重做为仿《明日方舟》风格的章节陈列，右侧滑出封面与章节选择。
- 分类界面改为斜向卡片堆与「云图」筛选，筛选路径与地址栏双向同步。
- 封面、章节与各节数据统一收拢到 `useSeries`。

### Fixed

- 修复云图命中范围与「鼠标在云上却点不中」的问题。
- 修复系列切换章节时的状态残留。

## [4.0.0] - 2026-08-08

### Added

- 配置 GitHub Actions 自动构建部署。
- 新增服务器部署脚本与资源路径处理。
- 页脚访问统计改为基于服务器日志生成 `stats.json`。

### Changed

- 站点代码全面重构，页面架构与组件拆分升级。
- Markdown 解析、代码高亮改为按需加载，降低首屏体积。

### Fixed

- 修复 Mermaid 图表加载失败、字体解析失败、背景图不显示等若干问题。
- 修复子路径部署下的资源路径问题。
