# 更新日志

格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号沿用站点公告中的命名。

## [5.0.0] - 2026-11-26

### Added

- 新增目录纯函数模型 `tocModel.js`，配 `test-toc.mjs`（54 条）与 `e2e-toc.mjs`（13 条）两个验证脚本。
- 新增公告结构化解析 `shared/utils/announcement.js` 与 `AnnouncementContent.vue`，公告弹窗与发布记录共用同一套渲染。
- 新增 `docs/` 文档体系（架构、指南、参考、运维、质量、ADR 与 AI 协作分册）、`AGENTS.md`、`CLAUDE.md`、Cursor 规则、Issue / PR 模板、CI 与 Dependabot 配置。
- 新增 `blogs/模板/` 写作模板与各模块 `README.md`。
- 内容：新增《编译理论总复习》、编译实验（文法解读 / 词法分析 / 语法分析）、计网导论与物理层、智能计算系统《深度学习应用》。

### Changed

- 重构 `src/` 目录：`views` + `components` 拆为 `features/`（按功能域）与 `shared/`（跨域复用）；`composables`、`stores`、`utils` 收入 `shared/`；`css`、`fonts`、根级 `style.css` 收入 `assets/`。
- 全站视觉重做：石英玻璃体系、归档页滚筒时间轴与移动端抽屉日历、重绘分类云图、卡片按博客类型统一配色、公告 / 设置 / 悬浮控件改为「纸面 + 黄绿」主题。
- 详情页重构：正文样式独立为 `blog-content.css`，重做标题、表格、引用、代码块与例题；布局、目录、浮动控件与上下篇导航同步调整，补版权说明与字数统计。
- 全站字号改为 `rem`，由 `html` 的 `clamp()` 根字号随视口等比缩放。
- 图片转 WebP 并预载首屏资源（首屏加载耗时约 -52%）；书法字体与图标拆成子集；收紧入场等待上限，资料卡背景图延后加载。
- 沉浸阅读补齐移动端：底部退出胶囊、安全区适配、平板目录断点调整到 1024px、悬浮球触控热区不小于 44px。
- 详情页搜索改为篇内段落级检索；代码块超过 10 行默认半展开；复选框可点并持久化；Mermaid 支持全屏与缩放。

### Fixed

- 修复自定义域名下资源路径错误导致的整站白屏；`dist/` 不再入库，改由 CI 构建。
- 修复图片未真正加载完即显示完成、公式占位符未还原、宽表格逐字换行、窄屏横向溢出。
- 修复短文章目录纵向居中、归档日历错位一天、移动端抽屉不可交互、滚筒卡片宽度参差。
- 修复 Windows + Node 22 下 `postbuild.js` 复制中文目录崩溃；同步 KaTeX 锁文件并简化 Markdown 正则转义。
- 修正文档中与实现不一致的路径引用（`src/css/` → `src/assets/styles/`）；lint 忽略 `blogs/**`，避免扫描 Obsidian 插件与主题脚本。
